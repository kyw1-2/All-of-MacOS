# All of MacOS 1.2.1 — Native Workspace and Fast Text Capture

Build `2026101708` (an earlier 1.2.1 build was superseded).

## Highlights
- Introduced shared design components for navigation, gesture editing, window tiling, Capture Studio, clipboard history, Insights and Settings.
- Restored entry points for application profiles, activation groups and previously inaccessible tiling editors.
- Improved clipboard-shelf responsiveness through targeted scroll updates, caching, background suggestions and reduced layout recalculation.
- Added an instant OCR mode with language-aware retries and a fallback for difficult text.
- Reduced expensive capture-history encoding, excessive URL-opening windows and idle gesture-preview activity.

## Verification and limits
The source documentation reports **782 passing tests**, including 10 performance regression tests. Synthetic UI inputs were exercised, but actual trackpad behavior was not comprehensively verified. Some external input types and hardware integrations remain outside validated scope.
