# All of MacOS 1.2.1 (2026101707)

Native UI redesign across the main window, a responsive Paste-style shelf, and instant Capture Text.

## Design

- Shared design system (`AOMDesignSystem.swift`): one set of spacing, corner radii, surfaces, page headers, metric/action tiles, empty states and toasts. Adaptive system colours only, so light, dark and Increase Contrast all work.
- Sidebar: native selectable rows for pages, application profiles (with gesture counts) and activation groups. The activation-group editor is reachable again (it existed only in an unused view in 1.2.0).
- Gestures: toolbar search, all six trigger categories in the filter, per-row enable switches, a list footer with add/remove, and a delete confirmation. On wide windows the canvas splits into actions and an inspector. An empty scope shows a guided "first gesture" screen instead of two blank panes.
- Window Tiling: a live preview stage beside the snap settings (collection, ⌥ requirement, preview), editors for snap zones, display profiles and saved windows (also unreachable in 1.2.0), and a 16-layout grid that tiles the front window.
- Capture Studio: 10 launch tiles (All-In-One, Area, Window, Fullscreen, Scrolling, Record, Capture Text, Previous Area, Self-Timer, QR/Barcode), a segmented filter, native context menus, and an empty state that fills the page.
- Clipboard: toolbar search, pinboard chips with counts, a type filter, and an "Open Shelf" button. Image thumbnails decode off the main thread.
- Insights: metric tiles with match rate, a ranked most-used list, and a setup summary.
- Settings window is resizable.

## Clipboard shelf (⇧⌘V) freezes

Measured with `sample` on the installed 1.2.0: every mouse move, scroll, click and key press ran `AOMScrollChromePolicy`, which recursively walked the view tree of every visible window.

- The scroll-chrome policy now refreshes only titled app windows, only the key window on per-event updates, at most once per second. Floating panels are skipped.
- `NativeScrollChrome` no longer schedules work on every layout pass.
- Cards are `Equatable`, keyed by store revision. App/file icons are cached, misses included. Banner colours are computed from raw pixels. Header titles and character counts no longer scan the whole clip.
- `visibleCardIDs` and `commandHeld` trigger a re-render only when the ⌘ badges would change.
- Search checks short fields first and uses a shared date formatter and tokenizer.
- Destination suggestions (Accessibility IPC, classification, ranking) run off the main thread. On-device model refinement is rate-limited.
- Retention trimming no longer bumps the store revision when nothing expires. Image-OCR index results wait until the shelf closes.
- Window snapping no longer does an Accessibility hit test on every mouse click, in any app. It waits until a drag starts and ignores AOM's own floating panels.

## Capture Text

- Instant recognition (new setting, on by default) is one accurate Vision pass with the user's top languages plus English. If one non-Latin script is misread under an English-first system, there is a single re-read for that script and a single upscaled re-read for tiny text. The multi-pass voting pipeline with Live Text remains the fallback for mixed CJK and low-confidence results.
- Vision, ScreenCaptureKit display content, system sounds and the result HUD are pre-warmed. Display content is reused until the screen layout changes.
- Feedback sounds use System Sound Services instead of `NSSound`. The first `NSSound.play()` measured 4.3 s on the main thread.
- Capture-history PNG encoding and manifest writes moved to a background queue. The link detector is shared.
- The selection overlay accepts the first click, so a drag starts even though AOM is not active.
- Stage timings are logged under `com.kyw.allofmacos` / `capture-text` (info level).

## Other

- New `aom://open-clipboard` deep link.
- Regression tests: `AOM121PerformanceTests` (10 tests). The full suite passes with 782 tests.

## Verification limits

- Live QA used synthetic input on this Mac (macOS 27.2). Some synthetic drags were not picked up by the selection overlay, which looks like a test-harness artefact. Real trackpad input was not exercised.
- The parity gaps listed in 1.1.4 remain: Magic Mouse surface, Touch Bar/Stream Deck/MIDI, BTT floating menus and widgets.
