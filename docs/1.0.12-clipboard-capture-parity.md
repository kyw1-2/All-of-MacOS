# All of MacOS 1.0.12 (2026101401)

Clipboard and capture interaction update based on the supplied Paste 7.0.2 and CleanShot X 5.0.1 requirements.

- Clipboard cards use content-type colors, compact source icons, 14 pt corners, and selected-card borders/shadows. Double-click, Enter, and visible-card Command-1…9 shortcuts paste into the captured destination after animated dismissal; Shift requests plain text. Command-C copies without dismissing. Copy/paste actions include system sound feedback.
- Search expands with a spring and respects Reduce Motion. Filters group content type, source app, calendar dates, device indicators, and pinboards. Device synchronization metadata is not present in the existing model; iPad and iPhone indicators are informational, not working remote-device filters.
- Quick Access uses refined material/stroke styling and pill hover feedback, exposes Copy 1x, freezes its countdown using monotonic elapsed time, and snapshots Option at native drag completion to invert the saved close-after-drop preference.
- Annotation supports centered 28 pt numbered badges with starting/reset controls, 8/16/32 px mosaics, adjustable Gaussian blur, and live privacy-effect previews. Corrects Retina source-region coordinates. Expanded canvas export includes padding presets, rounded screenshot corners, floating shadows, Sunset/Ocean/Sequoia multi-stop gradients, and a real blurred-image background.
- Resize includes an interactive aspect-ratio link, pixel/percent units, flattening warning, and existing Escape/Return actions.
- Pinned captures support Command-T/context-menu click-through, border dimming, trackpad magnification, wheel opacity, and 0–9 opacity shortcuts. Command-T over the image restores a click-through pin when keyboard monitoring permission is available.

Release preparation: compiled, signed, and packaged for distribution. Tests, application/UI execution, separate code/signature/DMG verification, and independent review were not run at the user's request. Pixel-perfect or behavioral parity has not been independently established. Existing test files and clipboard/capture storage schemas are retained. Compilation still emits concurrency/deprecation warnings in other existing application components; this release does not migrate the project to Swift 6 language mode.

Uses public system sounds and original gradient presets; no proprietary reference-app assets are included. The app and XPC helper use the existing AOM Dev self-signed identity; this is not an Apple Developer ID notarized release.
