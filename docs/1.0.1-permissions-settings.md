# All of MacOS 1.0.1 — Permissions Dashboard

An independent **Permissions** tab is available in the macOS Settings window, between Appearance and Capture. Each permission row opens the matching Privacy & Security pane; the row is mouse-clickable and its Open button is keyboard-accessible.

## Public system status checks

- **Accessibility:** `AXIsProcessTrusted()` — window automation and action control
- **Input Monitoring:** `IOHIDCheckAccess(kIOHIDRequestTypeListenEvent)` — event-listening capability, not necessarily a separate visible Input Monitoring toggle
- **Screen & System Audio Recording:** `CGPreflightScreenCaptureAccess()` — screenshots/recordings; macOS 26+ has the `Privacy_AudioCapture` settings pane, macOS 14–15 has `Privacy_ScreenCapture`
- **Microphone:** `AVCaptureDevice.authorizationStatus(for: .audio)` — optional until Microphone is selected as recording audio source

Optional access rows for **Automation**, **Files & Folders**, **Full Disk Access**, , **Full Disk Access**, and (macOS 15+) **Pasteboard** deliberately show **Check Manually**, because these grants are per-target, per-location, or per-use, and there is no reliable public aggregate authorization API. The app does not inspect the private TCC database or automatically grant any permission.

The ScreenCaptureKit preflight reports screen access, not an independent system-audio-only grant. The top summary shows only the currently relevant required permission count. The panel refreshes on appearance, after the application becomes active, and via the Refresh button. No automatic permission requests occur when opening this tab.

The System Settings deep links have a fallback to the general Privacy & Security page, and a visible error message if navigation fails.

## Validation

`AllOfMacOSTests/PermissionsSettingsTests.swift` tests OS-specific screen pane routing, all unique permission destinations, optional status semantics, microphone requirement conditionality, and labels. A real interactive UI and permission grant workflow must additionally be exercised on a Mac with attached displays and user-interactive login.
