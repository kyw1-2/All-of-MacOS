# AOM 1.1.1 — 카드 입력 수정과 로컬 기능 전수 대조

2026-10-16 · 빌드 2026101601 · 기준: 사용자가 제공한 AOM 1.0.14 / CleanShot X 4.8.8 / Paste 6.5.2 비교표. 아래는 현재 소스의 진입점과 구현 연결을 대조한 기록이다. 실행시험 통과표나 원본과의 동등성 인증이 아니다. 클라우드·공유·기기 간 동기화는 요청 범위에서 제외했다.

## 이번 수정

- ⌘⇧V 카드와 캡처 기록 카드의 `ImmediateMouseSelection`을 제거했다. 카드별 앱 전체 마우스 감시 및 수동 좌표 판정을 SwiftUI 카드의 단일/더블 클릭 배타 제스처로 교체했다. 단일 클릭은 선택, 더블클릭은 해당 카드의 동작을 실행한다. 드래그와 컨텍스트 메뉴는 유지한다.
- 카드·창 테두리는 hit testing에서 제외했다. 검색 후 카드 선택 시 AppKit의 검색 필드 편집기도 해제해 방향키와 Space의 대상이 선택 카드로 넘어가도록 했다.
- 더블클릭·Return·⌘1–9·미리보기 Return도 직접 붙여넣기 설정을 따르게 했다. 복사 후 창 닫기와 외부 앱에 붙여넣기를 분리했다.
- 복사·저장 실패 등의 `state.status`를 실제 클립보드 창 하단에 표시했다. 이전에는 대부분의 메시지가 상태에만 남고 창에는 표시되지 않았다.
- 여러 텍스트 카드는 하나의 텍스트 항목으로 합쳐 붙여넣는다. 하나의 pasteboard 항목만 읽는 앱에서도 첫 카드만 전달되지 않게 했다. RTF가 있는 항목은 가능한 경우 서식을 함께 합친다. 단일 항목의 원래 표현과 파일·이미지 다중 항목은 그대로 유지한다. HTML/RTFD만 있는 복수 텍스트의 서식 병합은 지원하지 않는다.
- Paste Stack에서 이미 삭제된 클립이 섞여 있어도 화면의 제거·맨 위로 이동 버튼이 원래 큐 위치를 사용하도록 했다. 같은 클립을 여러 번 쌓은 경우를 유지한다.
- 실제로 오늘 자정부터 필터링하면서 “Last 24 Hours”로 표시하던 메뉴를 Today로 바로잡고 Yesterday를 추가했다.
- 캡처 설정에 보존 기간과 250/500개 용량 선택을 노출하고 변경을 정리 정책에 연결했다. GIF 선택 시 효과가 없는 오디오 선택기를 비활성화하고 무음임을 표시한다.

## CleanShot 비교표 전체 항목

경로는 저장소 기준이다. 서비스는 `AllOfMacOS/Services/`, 화면은 `AllOfMacOS/Views/`, 앱 진입은 `AllOfMacOS/App/`에 있다.

| 비교 항목 | 구현 연결 | 남는 경계 |
|---|---|---|
| 영역·전체 화면 | CaptureMenu → CaptureCoordinator → ScreenCaptureService | 권한·배율 실사용 확인 미실시 |
| 창·활성 창 | captureWindowFromPicker / captureActiveWindow → captureWindow | 그림자·투명 영역 픽셀 비교 미실시 |
| 이전 영역 | capturePreviousArea, lastAreaDisplayID와 로컬 좌표 변환 | 모니터 재배치 결과 확인 미실시 |
| All-In-One | captureAllInOne → SelectionOverlay의 Area/Window/Screen/Scroll/Record/Text | 독립 UI, 원본의 모든 세부 조작과 동일하다고 판단하지 않음 |
| 세로 스크롤 | ScrollingCaptureSession → appendFrame(vertical) | 역방향·동적 콘텐츠·고정 요소 연결 품질 미측정 |
| 가로 스크롤 | 같은 세션의 horizontal 방향 | 앱별 연결 품질 미측정 |
| 타이머 | captureWithSelfTimer / runSelfTimerIfNeeded | 실시간 카운트다운 확인 미실시 |
| 십자선·확대경·화면 고정 | SelectionOverlay, CaptureSettings의 pixelSnap/freezeScreen | 화면별 좌표 검증 미실시 |
| OCR·QR | TextRecognitionService, Vision 텍스트/바코드 요청 | 언어·이미지별 인식률 미측정 |
| Quick Access | QuickAccessOverlay, QuickAccessDragSource, QuickAccessPolicy | 저장·복사·주석·드래그·닫기 경로 있음; 대상 앱별 드롭 확인 미실시 |
| 확대 미리보기 | QuickAccessExpandedPreview의 Fit/배율/키 처리 | 화면 크기별 실사용 확인 미실시 |
| 캡처 기록 | CaptureHistory + MediaHistoryOverlay + CaptureSettingsView | 개수·기간 정책이며 원본 저장소와는 독립 |
| 플로팅 스크린샷 | PinnedScreenshot의 lock/opacity/clickThrough, 복구 키 | 실제 포커스 전환 확인 미실시 |
| 주석·도형·화살표 | AnnotationEditor → AnnotationDocument.render | 도구별 렌더링 비교 미실시 |
| 블러·픽셀화·가림 | AnnotationDocument의 blur/pixelate/redact | Solid Redact는 불투명 덮기. 블러·픽셀화의 비식별화 안전성 보증 없음 |
| 자르기·리사이즈·회전 | AnnotationDocument crop/resize/transform와 editor 명령 | 일부 변환은 주석을 평면화함 |
| 배경·패딩·그림자 | AnnotationBackground, AnnotationEditor 옵션 | 프리셋과 렌더링은 AOM 자체 구현 |
| 편집 가능한 프로젝트 | AnnotationProject.write/read ↔ AnnotationEditor.saveProject/openProject | .aomannotation 자체 형식, 원본 픽셀 포함 |
| WebP | CaptureFormat.webp → ScreenCaptureService.encode / WebPEncoder + 번들 libwebp | 외부 Homebrew 없이 배포 번들 코덱 사용 |
| MP4 녹화 | ScreenRecordingService → AVAssetWriter H.264 | 실제 녹화 결과 확인 미실시 |
| 시스템+마이크 | computerAndMicrophone → 두 입력 트랙과 종료 시 믹싱 | 마이크는 macOS 15 이상, 믹싱 실패 시 원본 보존 |
| 녹화 일시정지·재개 | HUD·CaptureMenu·CaptureShortcuts·URL → pause/resume | 영상·오디오 동기화 실측 미실시 |
| 카메라·키 표시 | RecordingCameraSource / 키 이미지 → 프레임 합성, CaptureSettingsView | 최종 영상에 합성되어 독립 레이어로 제거 불가 |
| GIF | 설정 gif → 녹화 종료 → RecordingExportService | 최대 120초, MP4 원본 유지, 무음 |
| 녹화 후 편집·Zoom Timeline | RecordingExportEditor → RecordingExportService | AOM 자체 편집기. CleanShot 5.x 기능을 설치본 4.8.8의 기능으로 계산하지 않음 |
| 파일명 템플릿 | CaptureSettings 파일명 토큰 + CaptureSettingsView 미리보기 | 원본의 모든 템플릿 문법을 호환하지 않음 |
| URL Scheme | AppDelegate의 AOMCaptureDeepLink.parse 및 dispatch | aom:// 자체 명령, cleanshot:// 가로채기 없음 |
| Finder 연동 | AppDelegate Services/파일 열기 + AnnotationPreview.appex | AOM 프로젝트 Quick Look와 Services 제공. 원본의 전용 공유 확장과 구조가 다름 |
| CleanShot Cloud | 제외 | 계정·업로드·공유 링크 구현 대상 아님 |

추가 지적 항목: ScreenCaptureService.captureArea는 교차하는 디스플레이 조각을 합성하고, ScreenRecordingService는 여러 스트림을 하나의 선택 영역으로 합성한다. RecordingRecovery는 fragmented MP4와 저널을 사용한다. 원본과 동일한 멀티모니터 화질·중단 복구 성공률은 확인하지 않았다.

## 점검 범위

수정 전 1.1.0의 실제 앱 메인 화면·일반 설정 화면과 격리 샘플 클립보드 카드 화면을 열었다. 실제 사용자 클립보드 기록 대신 미리보기 모드의 7개 샘플 항목으로 카드 배치를 관찰했다. 이후 Mac 잠금으로 클릭·스크롤·크기 변경·편집 시나리오의 화면 점검을 계속할 수 없었다. 수정 버전의 UI 통과 판정은 하지 않는다.

마지막 사용자 요청에 따라 자동 테스트, 회귀시험, 픽셀 비교, 별도 독립 검증을 실행하지 않는다. 배포에 필요한 release 컴파일, 확장/도우미 빌드, 코드 서명과 패키징만 수행한다. 이번 대조에서 발견한 구체적인 입력·설정·자료 전달 차이를 수정했으며, 표의 제한을 전체 기능 동등성으로 바꾸지 않는다.
