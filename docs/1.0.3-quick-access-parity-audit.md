# All of MacOS 1.0.3 — Quick Access parity audit

Reviewed official CleanShot X feature list, changelog and Quick Access URL-scheme documentation (cleanshot.com/features, cleanshot.com/changelog, cleanshot.com/docs-api).

## Fixed behavioral mismatches

- Floating panel now becomes key so keyboard commands can reach it; handlers remain scoped to its own window.
- Save and Reveal in Finder are separate, even with "Ask for Name" enabled.
- Save All and Close All operations are available in both capture menu and card context menus. Failed saves preserve the card.
- Recently closed item UUIDs persist across app restarts and are validated against the existing capture history cache. Original media are not copied or deleted by restore.
- Existing PNG, JPEG, HEIC, TIFF, MP4 files can be imported through the native file chooser. Original files remain unchanged.
- Small overlay sizes now use their exact configured width; stack placement adapts to shorter screens instead of collapsing all cards to one position.
- Failed Finder Trash/recycle operations preserve keyboard monitors and the overlay. Duplicate recycle attempts are blocked.
- Temporarily Hide now retains all panels and pauses timers, with a matching Show action in the Capture menu.
- Auto-close supports either Close or Save Before Auto-Close. A failed save leaves the card available for retry. Delays extend to 5 and 10 minutes.
- Three additional Quick Access tests cover bounded positioning, restored history IDs, and external file integrity.

## Still not equivalent

CleanShot Cloud managed links, cloud password restrictions, proprietary editable .cleanshot projects, premium integrations, and feature-by-feature visual fidelity are not implemented. Native macOS Share Sheet is not equivalent to proprietary cloud sharing.

The project needs interactive visual QA on an attached-display Mac, and drop testing with real third-party targets. No 99% parity claim is made.

Distribution is a separate ad-hoc testing DMG until the AOM Dev Code Signing identity becomes usable. Existing installation and user presets must not be overwritten.
