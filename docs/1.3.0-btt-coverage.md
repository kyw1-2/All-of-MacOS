# BTT 6.957 comparison follow-up — local feature coverage

Based on `AOM-1.2.8-vs-BTT-6.957-REA-Ghidra.md` (2026-10-20). Original AOM code, based on documented capabilities, public Apple interfaces and the existing AOM source; no recovered commercial implementation is embedded. BTT's bundled catalogue establishes feature names, not behavioural equivalence. The entry-point Ghidra results do not establish entire-product parity.

User exclusions: cloud/account/mobile cloud, Magic Mouse and Stream Deck. “Existing” means a source implementation, not a hardware acceptance result. “Added” also requires the release test log; attached device and GUI acceptance remain distinct.

## New deterministic and integration checks

`AutomationExpansionTests`: menu action/widget persistence and duplicate/invalid import rejection; streaming MIDI/running-status/realtime/zero-velocity Note Off; raw original-allocation MIDI packet traversal with multiple and >256-byte packets; MIDI/gamepad/HID value/device filters and Codable/source registration; script failure/status/truncation; AX selector ambiguity avoidance; seven image-matcher tests (exact/noisy/transparency/budgets/cancellation/raster orientation/display-coordinate conversion/invalid configuration); overnight weekday and inclusive date windows; same-day-of-month scheduling regression; actual filesystem missing-file creation and repeated atomic replacements.

Hardware monitors use public CoreMIDI, GameController, IOHID, CoreWLAN/IOKit APIs. Tests do not imply that a device was attached. Release-level results and any test failures belong in the final release validation log.

## BTT preset import (3.3.3)

This replaces the 1.3.0 "JSON subset" section (two trigger kinds, eight action IDs, whole-trigger
rejection). `Services/BTTPresetImport.swift` and `Services/BTTImportMappings.swift` were rewritten
in 3.3.3 (btt-import a1f3d65, tests beacb32). Import Preset offers `.json` and `.bttpreset` files
(integ-core aaf9386); a native AOM preset is recognised first and imported as before.

Input: one copied trigger, an array of copied triggers (⌘C in BTT), or a plain-JSON `.bttpreset`
(`BTTPresetContent` app groups). Compressed `.bttpresetzip` / `.bttpresetcompressed` files are
refused with an export hint. Limits: 8 MB, 2,000 triggers, 64 actions per trigger, depth 32,
250,000 JSON values, strings up to 1 MB.

What maps:

- Trackpad: all 152 IDs of BTT's trackpad catalog are known; 95 map (6 approximately) and 57 are
  skipped by name. The four trackpad classes map, the device-limited ones approximately.
- Keyboard: shortcuts (type 0/−1) with modifiers including the left/right device bits, key down
  and up, minimum and maximum hold time; the long-press, release and quick-release categories
  become separate AOM triggers. Key sequences (624) keep held modifiers
  (`BTTKeySequenceMixedKeys`), optional keys and order; the gap is clamped to 100–2,000 ms.
- Normal mouse 996–999 and 1000–1299: click, double and triple click, scroll, and the
  drag-direction and long-press categories as AOM mouse gestures.
- Named triggers (643), and 38 Other trigger IDs that have an AOM `SystemTriggerKind`: sleep and
  wake, lock, screen saver, Space, power, battery level, Wi-Fi, USB and Bluetooth, display, screen
  corners and edges, app launch, quit and activate, variable, file, clipboard, input source, audio
  output, and interval, daily and weekly times.
- Actions: about 180 documented IDs (79 exact, 14 approximate, 42 with converted settings, 20
  F-keys, 18 modifier down/up, Desktop 1–9). 58 more IDs are known by name, so a skipped step
  shows its BTT name.

Scope and state: `BT.G` becomes All Apps; an app group becomes the trigger's `appBundleID` plus an
`AppTarget` at merge; other `BT.*` groups are skipped. `BTTEnabled` / `BTTEnabled2` are kept for
exact matches; approximate matches arrive disabled. `BTTTriggerTypeDescription` becomes the name,
`BTTGestureNotes` stays at the top of the notes, followed by the BTT ID and every approximation
reason, and `BTTOrder` keeps the order within a scope. `BTTDisableGlobalTriggers` is reported.

Report: three groups, Imported, Mapped Approximately and Skipped (`BTTImportReportView`, the
review alert's accessory). Each entry names the BTT trigger, its class, ID and scope, what it
became and why. A dropped action stays in its trigger as a disabled "Not imported: … (BTT id)"
step in its place. IF/ELSE and Repeat skip the whole trigger, so a conditional step never becomes
unconditional. BTT keys AOM does not know are named, not dropped silently. Named-trigger names
that already exist in the preset are listed.

Safety: AppleScript, JXA, shell and terminal commands, Apple Shortcuts, runnable files (`.command`,
`.sh`, `.scpt`, `.workflow` …) and URLs other than http(s) and mailto arrive disabled with a
Review flag. Every value is type- and range-checked: booleans are not integers, strings carry no
control characters, paths are absolute, bundle IDs are validated, and embedded JSON strings are
parsed with the same limits. A malformed value skips only its trigger, and unknown JSON never
crashes the importer (seeded byte-mutation tests). Every staged trigger passes
`PresetCodec.decode(encode())`, the check the preset store applies when saving. Importing never
replaces the preset or runs an action.

Not imported, and reported where it occurs:

- Classes without an AOM input: Magic Mouse (all 62 IDs), drawings (BTT does not document how it
  stores the shape), Touch Bar, Stream Deck, Notch Bar, floating menus, MIDI (BTT keeps the learned
  note outside the JSON), generic devices, Siri Remote, BTT Remote, gamepads.
- Trackpad: continuous gestures 244–256, finger-harder variants (176, 177, 180, 181, 188–193),
  TipTap left/right and TipSwipe, 2-finger edge swipes 236–243, 4/5-finger force click, 3-finger
  drag, click-swipes, triangle swipes, the 11-finger tap, custom tap sequences, partial release
  220, "5 Finger Touch" 151.
- Keyboard: special keys from 1000 (media keys, Caps Lock 1004), modifier-only shortcuts, the
  "release after long press" (37) and "after all modifiers released" (47) categories, device
  configurations. Mouse: quadruple clicks, the Logitech thumb wheel, release categories 31–33 and
  60, continuous drags.
- Other triggers without an AOM kind: text selection changed 806, power mode changed 848, lid,
  Spotlight, notch, focused-window events, Dock and menu-bar icon events, distributed notification
  received 607, OSC received 850, audio input changed 834, mouse leaving a corner or edge, script
  output, CAG activation, launcher items, AI triggers, Key Remap 805.
- Actions with an AOM type but no converter yet: Bluetooth device 274–276, MIDI 462, OSC 602,
  Cycle 335, Toggle On/Off 346, Increase Variable 412, Ask For Input 403, Debounce 579, window
  layouts 268–270/513/580, pin and unpin window 337/338/401/402, window switcher 99/100, change
  input source 420, haptic 255, Custom Click 119, Move Mouse 153, Scroll 272.
- Actions without an AOM type: Move Window to Desktop N (216–245), Desktops 10–19, F21–F24, Core
  JavaScript 281, JavaScript in the browser 600, Automator 138, custom move and resize formats
  251/446, screenshots, ChatGPT and AI, OCR, Night Shift, True Tone, Siri, keyboard illumination,
  external brightness, hide or show all windows, enabling a trigger by BTT UUID.
- BTT conditions (`BTTTriggerConditions*`, `BTTConditionName` …) make a trigger approximate; `BT.*`
  special groups, preset-level settings and snap areas are ignored; plugins and compressed or
  bundled presets are refused.

Caveats: AOM's Spaces and Desktop actions need the macOS ⌃←/⌃→ and ⌃1–9 shortcuts; those mappings
count as exact and are not flagged per trigger. AOM volume steps are 6 points (macOS uses 6.25).
Whether AOM's left click carries held modifiers, as BTT 3 says BTT's does, was not checked.

Evidence and tests: the mapping follows the JSON references bundled with BTT 6.908
(`trigger-definitions.mdx` and `action-definitions.mdx` in its Resources, read only) and public
example exports; no vendor code was copied. No real user preset was read, and the review dialog
was rendered only in a unit test. `BTTImport333Tests` (15 tests: every trackpad and Magic Mouse
catalog row, the action rules, keyboard phases and modifier sides, sequences, mouse gestures,
Other triggers, script and link safety, placeholders, hostile input with 300 seeded mutations, a
`.bttpreset` read from a temporary file, a merge into an isolated `AppState`, the report view) and
`BTTPresetImportTests` (8 tests; five assertions of the old policy were updated).
