## Scope and remaining gaps

- Implemented families: trackpad contact/hold/release/edge gestures; normal mouse multi-click/hold/drag/scroll; keyboard hold/release/optional sequences; system events; window/input/system/control-flow actions.
- This release does not implement a Magic Mouse touch-surface driver, Touch Bar/Stream Deck/MIDI/gamepad/Siri Remote device support, BTT Mobile, or BTT floating-menu/widget engine.
- Bluetooth and Wi-Fi events depend on system permissions; app/window automation depends on Accessibility and macOS shortcuts. These hardware-dependent paths were not exhaustively exercised.
- GUI completion: trigger notes, color labels, folders/grouping, copying with fresh nested IDs; menu-bar pause; global gesture/timing/suppression settings; live workflow variable editor.
