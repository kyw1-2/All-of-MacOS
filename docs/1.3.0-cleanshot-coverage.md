## Persistence and original preservation

A source MP4 is never overwritten by Studio export. Cursor/click/shortcut metadata is stored locally as `.mp4.aom-cursor.json`; old cursor-only JSON remains readable. Camera is `.mp4.aom-camera.mp4`; editable project is `.mp4.aom-studio.json`. Projects bind to the original filename, byte size and duration; bounded decoding/validation rejects unrelated or corrupt state. Edits save automatically after settings changes and on closing; sequence edits also save immediately.

After a recording with editable layers stops, AOM renders a standalone presentation MP4 for external players. Original media and sidecars are retained. A small `.mp4.aom-source.json` local link lets Edit Recording reopen the original; path traversal, missing and non-MP4 targets are rejected. Rendering failure retains the raw recording and reports a warning. Copying the presentation alone preserves playback; further independent layer editing requires its original local files.

## Verification

An isolated macOS Swift package compiles the production cursor/timeline/renderer/export service **and the full SwiftUI RecordingExportEditor**. `StudioTimelineTests` plus independent `RecordingExportTests` execute real synthetic H.264 encode/decode, MP4/GIF exports and pixel assertions. The final isolated run at 2026-10-20 21:23 KST, including presentation source-link round-trip and traversal rejection, passed **28 tests / 0 failures** (18 timeline, 10 media tests). Full application build and integration results are recorded by release integration.

These tests cover source bytes remaining unchanged, nonzero playable MP4, selected duration, reordered source pixels, 1280-square canvas, square GIF/frame count, camera-sidecar frame decoding, camera-layer movement/hiding, cursor-source timestamps, old metadata compatibility, click clustering/ripple boundaries, project recovery/source mismatch and invalid range rejection. Sequence preview uses a real AVMutableComposition and the same renderer; its SwiftUI path is compiled, while interactive playback timing is runtime unverified.

Still requiring physical-device tests: ScreenCaptureKit permission/start-stop, global event-monitor permission, real camera/mic/headset capture and switching, long recording/crash recovery, multi-display/Retina capture/selection, scrolling stitch quality, Finder extension installation, and encoder throughput. Unsupported interchange/semantic extraction items above are not represented as completed parity.
