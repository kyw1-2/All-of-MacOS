## 남는 차이

- 클라우드 업로드, Raycast, 링크 웹 미리보기, 공유 핀보드/iCloud, Annotate 배경 사이드바(팝오버 유지), 텍스트 스타일 프리셋·Spotlight 모양/불투명도, AIO 비율 메뉴·선택 영역 리사이즈 핸들, 객체 복사(⌘C)는 미구현.
- 크기·여백·애니메이션 곡선 일부는 레퍼런스에서도 미확인 값이라 AOM 자체 값이다.
- 카드·필터·선택 링·Quick Access·Pin·History·Annotate는 격리 미리보기(`--aom-ui-preview`)로 화면을 확인했다. All-In-One 전체 화면 오버레이, NSMenu, 실제 트랙패드 스와이프, 실제 앱으로의 붙여넣기는 실기 확인하지 않았다.

- `swift test -j 6`: 533개 중 532 통과. 실패 1개 `ScreenCaptureTests.testEveryFormatEncodes`는 `swift test` 환경에 번들 libwebp가 없어 WebP 인코딩이 실패하는 것. WebP 관련 소스는 변경하지 않았다.
- `ALLOFMACOS_SIGN_ID="AOM Dev" ALLOFMACOS_SKIP_AUTO_RELEASE=1 ./build-and-sign.sh`: release 빌드, XPC·확장·libwebp 포함 서명, `codesign --verify --deep --strict` 통과. GitHub 배포는 하지 않았다.
