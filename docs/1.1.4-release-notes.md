# All of MacOS 1.1.4 (2026101703)

Completes the interrupted 1.1.4 work tree based on 1.1.3 (`e0212747b01a`). The source was edited directly in the supplied Downloads folder.

## Changes

- Expanded catalogs to 179 actions (+74) and 110 trackpad gestures (+24). Added contact start/long-touch/release/edge gestures, keyboard long-press and quick-release phases, normal-mouse multi-click/hold/drag/scroll recognition, and system event triggers.
- Added window geometry and pointer-follow actions, synthesized input, Spaces/system/utility actions, repeat/break/cycle/toggle/debounce/wait control flow and variable operations. The action picker includes searchable descriptions, parameter forms and copied actions with new nested IDs.
- Completed trigger notes, color labels, folders, optional grouped list, metadata search, copying/pasting into the current scope and duplication with fresh trigger/action IDs.
- Added menu-bar pause for five minutes, one hour, until resumed, or per app; global gesture/timing settings and modifier/typing suppression; an Automation → Workflow Variables window for live inspection, editing and deletion.
- Fixed paused trackpad clicks/pointer suppression, repeating-trigger pause checks, stale callbacks for removed/disabled triggers, mouse down/up pairing after a missed release or registration update, and cleanup of synthesized modifiers/window dragging when stopping all sequences or quitting.
- Isolated workflow variables in tests, made WebP encoding tests load the developer codec, added the Bluetooth usage description and observation of already-connected paired devices, and supported a build scratch directory outside Downloads.

## Compatibility and scope

Existing preset fields retain their decoding defaults. Trigger copies get new identities while preserving their settings; pasted copies use the selected app/group scope. Per-gesture swipe thresholds override the new global default. Runtime pause state is not persisted.

This release is **not full BetterTouchTool parity**. The [catalog comparison](1.1.4-btt-catalog-comparison.md) includes individual supplied action/trackpad labels, unmapped entries and unsupported device families. Exact label matches are catalog candidates, not proof of identical runtime behavior. Magic Mouse touch-surface, Touch Bar, Stream Deck, MIDI/gamepad/Siri Remote, BTT Mobile and BTT floating-menu engines remain outside this release.

Bluetooth/Wi-Fi, external devices and all macOS automation combinations were not exhaustively tested on hardware. Bluetooth and named Wi-Fi events require the relevant system permissions; window/input automation requires Accessibility. macOS Spaces actions depend on enabled system shortcuts.

Break Loop leaves the nearest repeat loop. Outside a loop it intentionally ends the sequence; this behavior is covered by tests.

## Build and verification

The final full XCTest run passed **761 tests with zero failures**, including BTT trigger/action tests and new regression tests for stale trigger callbacks, native mouse pairing, pause behavior, variable isolation, copied identities and global sensitivity. The independent review findings were checked against code and deterministic tests; the alleged out-of-loop Break Loop issue is the explicitly tested behavior described above.

Use Xcode and install the WebP development codec (`brew install webp`). Build databases stay outside Downloads:

```sh
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer swift test --scratch-path "$HOME/.cache/aom-1.1.4-final" -j 4
ALLOFMACOS_SCRATCH_PATH="$HOME/.cache/aom-1.1.4-release" ALLOFMACOS_SKIP_AUTO_RELEASE=1 ./build-and-sign.sh
codesign --verify --deep --strict 'build/All of MacOS.app'
```

The release uses the existing local AOM Dev signing identity and is not Apple-notarized. Compiler warnings about Swift 6 actor/sendability migration remain; the package uses Swift 5 language mode.
