# All of MacOS 1.1.4 — Expanded Gesture Automation

Build `2026101703`.

## Highlights
- Expanded the action catalog to 179 entries and the trackpad gesture catalog to 110 entries, with additional press, release, edge, keyboard and mouse-trigger variants.
- Added trigger folders, colors, notes, metadata search, duplication, and copy/move workflows across application scopes.
- Added global gesture settings, pause/resume controls, and workflow variable support.
- Corrected cleanup of pending callbacks, mouse button pairing, synthetic modifiers and window dragging when triggers stop or configurations change.
- Improved behavior with existing presets and expanded tests for trigger identity, pause state and variable isolation.

## Verification and limitations
The final source reported **761 passing tests and zero failures**. Local development builds use the existing self-signed AOM Dev identity and are not Apple-notarized. Device-specific inputs, system permissions and every automation combination were not exhaustively exercised. Technical coverage notes remain in separate audit documents.
