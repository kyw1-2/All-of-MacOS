# All of MacOS 1.5.0

Build `2026102103`.

## Main window rebuilt

1.4.0 replaced Settings. 1.5.0 replaces the window that holds everything else.

The old main window stacked three navigation systems: a `NavigationSplitView`
sidebar, a system toolbar and a per-page `navigationTitle`. Page titles moved
depending on which pane had focus, the toolbar changed shape per tab, and the
home screen competed with the sidebar for attention.

- **One navigation rail.** Fixed 236 pt rail with the wordmark, a live automation
  status pill, six destinations and a scope menu (All Applications, app profiles,
  activation groups). Selection is a tinted pill; the gesture count sits inline.
  Settings, the onboarding tour and the version live at the bottom.
- **One page header.** Every destination shares the same 58 pt header: title and
  one-line description on the left, search (⌘K), a single Capture menu, and
  diagnostics on the right. No more toolbar that disappears or reorders.
- **New home screen.** Time-aware greeting, a status chip that pauses automation
  in one click, two large primary actions (capture, clipboard), two secondary
  actions (text extraction, screen recording), three metric cards that jump to
  their section, and a two-column activity layout that collapses to one column
  under 980 pt.
- **Consistent canvas.** Pages render inside the same background and separator
  system; the diagnostics drawer docks on the right instead of competing with the
  sidebar.

## Verification

- `swift build -c debug` and `swift test -j 2` on macOS 27.2 / Xcode 27.1.
- Release build through `build-and-sign.sh`, signing with the AOM Dev identity.

## Scope

Source-level change. This release claims the window structure and home layout
changed; it does not claim runtime, performance or visual equality with any
third-party app.
