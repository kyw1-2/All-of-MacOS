# All of MacOS 1.3.0 — Expanded Local Workflows

Build `2026102001`.

This update expands AOM's on-device clipboard, capture, recording and automation capabilities. Account-based cloud services and several specialized device integrations are outside the release scope.

## Clipboard management

- Native multi-file drag preserves file order and produces separate drag items.
- Pinboard tabs, pinned items and clipboard-stack entries can be reordered.
- Added search chips, suggestions, OCR-match highlighting and configurable insertion modifiers.
- Extended keyboard navigation for boards and streamlined compact clipboard presentation.
- Native color editing preserves color information as well as hexadecimal text.
- Link previews are opt-in; their ephemeral WebKit session disables JavaScript. Opening a remote link preview may still contact that website.
- Existing encrypted archive and key locations remain unchanged; optional ordering metadata remains backward-compatible.
- On-device OCR can supply extracted text when image attachment is unavailable. OCR text is not equivalent to full image understanding.

## Capture, recording and editing

- Added click-guided zoom suggestions, cursor presentation controls and ripple settings.
- Editing supports ordered recording segments, splitting, removing and reordering ranges, with MP4 and GIF export.
- Recording projects can preserve separate original screen and camera tracks and shortcut telemetry for subsequent edits. Effects baked into legacy exports cannot be recovered as independent layers.
- Camera overlays, shortcut labels, aspect ratios and output resolution presets are configurable.
- Image exports can retain an existing color profile or convert to sRGB.
- Finder Quick Look, thumbnail and Share extensions expand native workflows. Actual availability depends on extension enablement and the host application.

## Automation and input

- Added configurable floating action menus with buttons, variable/clock widgets and reusable definitions.
- Added application-scoped Touch Bar controls.
- Expanded configured MIDI, controller and explicitly selected HID inputs; these require appropriate devices and OS permissions.
- Improved file, USB, Bluetooth, Wi-Fi and timed trigger editors, pattern filters and watcher recovery.
- Script results and completion status can populate workflow variables; Swift execution requires an installed command-line toolchain.
- Added process-targeted keyboard actions and bounded Accessibility operations.
- Permission-scoped local automation tools can configure named triggers and queue stored actions. The bundled `aomctl` command-line interface uses local app commands and authorized scopes without opening a network listener.

## Validation boundaries

The implementation and audit materials distinguish delivered functionality from partial support, operating-system restrictions and hardware behavior not verified on attached devices. This release does not claim universal integration compatibility or matching functionality across all third-party software. Technical evidence and detailed comparison ledgers remain available separately in the repository.

Signing, build provenance and test results should be taken from the corresponding GitHub release artifact; this overview does not add unverified test claims.
