# All of MacOS 1.3.0

This update implements local feature gaps identified in the 2026-10-20 Oracle audit of AOM 1.2.8 against CleanShot X 5.0.1, BTT 6.957 and Paste 7.0.2. Cloud/account/sync, Magic Mouse and Stream Deck are excluded. Vendor binaries, decompiled source and private assets are not bundled.

## Clipboard

- Every file in a multi-file clip becomes a separate native drag item; files retain their order.
- Pinboard tabs, their items and Paste Stack can be reordered. Stack uses an adaptive height and a default ⇧⌘C shortcut.
- Inline search filter chips, suggestions and OCR-match highlighting; configurable Quick Paste and Plain Text modifiers; next/previous board shortcuts.
- Native color editing preserves color data and hexadecimal text. Detachable previews and compact/sliding shelf presentation.
- Link previews require opt-in, use an ephemeral WebKit store and disable JavaScript. Loading a preview still contacts its website.
- A capture-visibility preference requests exclusion using the platform API; capture applications and newer OS behavior can ignore it.
- macOS 26 can supply local Vision OCR text from the destination screenshot to the text model. macOS 27 retains supported direct image attachment. OCR is a fallback with different capabilities, not full image understanding.
- Encrypted archive paths and keys are unchanged. Optional pinboard-order fields preserve older archive decoding.

## Capture and Studio

- Click events guide editable zoom suggestions, with cursor dwell as fallback. Cursor arrow/dot/hidden and ripple effects are adjustable.
- Append, split, remove and reorder source ranges; preview the sequence and export MP4/GIF with source-time effects.
- Save/recover editing state beside the original video; aspect and resolution presets.
- New recordings keep camera and shortcut layers separately. They produce a standalone presentation MP4 while preserving screen/camera originals and telemetry. Edit Recording resolves back to these originals.
- Camera size/position/roundness and shortcut size/position/visibility remain editable. Effects already baked into older recordings cannot be extracted or removed.
- Image output can preserve the display profile or convert pixels to sRGB.
- Signed Finder Quick Look preview, thumbnail and Share extensions; sharing supports Annotate and Pin. Extension enablement and host behavior remain system-dependent.

## Automation

- Native Floating Menu editor with action buttons, variable/clock widgets, reusable JSON definitions, pointer/center/notch-adjacent placement and ordinary action execution policies.
- Public application-scoped Touch Bar controls. These appear while AOM is active and do not replace other apps' Touch Bars.
- CoreMIDI Note/CC inputs, GameController extended/micro profiles and explicit VID/PID/usage generic HID inputs. Only configured devices are monitored; normal keyboard/mouse HID collections are excluded from the generic path.
- Exposed file, USB, Bluetooth, Wi-Fi and time-event editors, regular-expression filters, atomic-replacement/missing-file watcher recovery and date/weekday/overnight time windows.
- Swift/JXA/shell script results and exit/timeout status can populate workflow variables. Swift execution needs an installed Xcode command-line toolchain.
- PID-targeted shortcuts and bounded Accessibility title/identifier/role press/value actions.
- Local MCP automation tools use a separate per-client opt-in scope. Existing clipboard clients retain their original scope. Automation can configure named triggers and menus and queue stored actions; normal OS permissions still apply.
- Bundled Python 3 CLI: `All of MacOS.app/Contents/Resources/bin/aomctl`. Named UI commands use `aom://`; catalog/configuration commands require `AOM_MCP_TOKEN` for a client granted Automation in the UI. No network listener is added.

## Evidence and limits

The three linked coverage ledgers map all 126 audit rows to existing/new implementation, partial coverage and runtime unknowns. Retained REA evidence includes CleanShot structural analysis `ev_c3a13427743eb86cead6e2acbbc071dd1ddaed37185be0b87dc00503aa5473e9`, BTT helper entry evidence `ev_733336970a3d9e0a78ba7cae19256644d60fff0b956e5996415e91e50c4caedc`, and the older Paste 6.5.2 structural reference `ev_73dd336d7756f9a1f0908f788a4c259cb23ecf810178e9d681c60d5ddf787d9d`. The Paste reference is not a 7.0.2 binary. Entrypoint decompilation and class inventories do not prove feature algorithms or runtime equivalence.

No claim of 99% feature/UI/performance equivalence is made. Full BTT preset/plugin SDK compatibility, proprietary Logitech controls, arbitrary-video semantic zoom/extraction and every capture recipient/device/OS combination remain outside verified coverage. New public-API drivers do not establish successful operation with an unattached device.
