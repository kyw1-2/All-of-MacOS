# Paste 로컬 기능 적용 범위 — AOM 1.3.0

기준: 2026-10-20 KST의 `AOM-1.2.8-vs-Paste-local-comparison.md` 42행. 클라우드, 계정, 동기화, 공유 Pinboard는 제외한다. Paste 6.5.2 보관 바이너리/REA·Ghidra 자료와 Paste 7 공식 문서의 증거 경계를 유지한다. 이 문서는 Paste 7의 전체 실행 결과·픽셀·성능 동등성을 주장하지 않는다.

**표의 상태**: 기존=이전 구현 유지, 신규=이번 코드 추가, 부분=플랫폼/의미상 한계 존재. 모든 GUI 동작은 별도 실기 검증 항목이며 코드·단위 테스트 존재만으로 실기 성공을 판정하지 않는다. 아래 테스트는 검증 대상을 명시한 것으로, 최종 통과 수는 릴리스 담당자의 실제 테스트 로그를 따른다.

## 검증 경계와 남은 실기 항목

- 새 `ClipboardLocalGapTests`는 총 8개 논리/표현/마이그레이션 테스트다. 실제 마우스 드래그·모델 추론·타사 앱 수신·화면 공유 보안 효과를 증명하지 않는다.
- 최종 source freeze 후 전체 `swift test`/번들 빌드 결과와 실제 설치 결과는 릴리스 담당자가 별도 기록한다. 작업 중 다른 기능의 미완성 소스로 실패한 build/test 시도는 통과로 집계하지 않는다.
- 우선 실기: Finder 다중 파일→Mail/Notes/브라우저 드래그; RTF/HTML→Notes/Pages/Word; 색상 native UTI paste; Pinboard/Stack 실제 재정렬; 칩/한글 IME/Tab/Return/VoiceOver; compact/분리창/다중 모니터; macOS26 opt-in OCR·모델/권한 거절; 실제 공유 앱에서 노출 설정 효과.
- 링크 프리뷰는 사용자가 명시적으로 켤 때만 네트워크를 사용하며, 기존 비밀 클립 제외·암호화·데이터 복구 경계는 유지한다.
