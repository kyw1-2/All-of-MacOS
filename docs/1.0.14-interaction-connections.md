# All of MacOS 1.0.14 (2026101501)

This release connects clipboard and capture interactions that were left incomplete after the 1.0.13 visual update. The user requested implementation, commit, push and release without functional verification.

## Clipboard

- Handle preview keys in the popover window as well as the history panel. Space opens the selected item and a second press closes it; held-key repeats do not repeatedly open/close it. Closing restores keyboard focus to the timeline and retains selection.
- Add previous/next preview buttons and Left/Right navigation, with selection and lazy-shelf scrolling following the preview. Delayed presentation is canceled when a newer navigation or dismissal supersedes it.
- Connect preview Copy, Command-C/Shift-Command-C, Return/Shift-Return paste, Command-F search, Command-R rename, Command-E edit/save and Command-S save. Native selected-text copying remains available; spaces, arrows and Return remain text input while editing.
- Add a discard prompt when explicitly closing an edited preview. Disable interactive dismissal during editing using SwiftUI's presentation modifier; platform-specific outside-click behavior remains untested.
- Select the whole card, including its header, while preserving inline title editing, drag and double-click behavior. Command-click deselection no longer leaves keyboard focus pointing at an unselected item.
- Protect inline title editing and explicit search focus from card shortcuts. Use hardware key codes for common Command shortcuts so Korean input mode does not change their meaning.
- Retain an adjacent selection after keyboard deletion and remove stale selections/previews when filters or stored entries change.
- Focus text/name editors on presentation, use Command-S to save multiline content and show the item size limit before saving.

## Capture and annotation

- Close capture previews with Space or Command-W, ignore held-Space repeats and connect Command-0/1 to fit/100% zoom for images.
- Restore history keyboard navigation after selecting a card or submitting search. Connect Command-F/C/S/E/W and dismiss search, selection and history in stages with Escape.
- Preserve the adjacent history selection after deleting an item from history.
- Show options for the selected annotation's actual kind, including arrow style, rectangle corner radius and counter text, even in Move mode.
- Move selected annotations with arrow keys (one source pixel, Shift for ten), deselect with Escape and support Forward Delete. Selection-only clicks no longer create unnecessary Undo changes; Undo/Redo refresh the selection inspector.
- Connect Quick Access Command-Shift-S, protect text inputs and modal dialogs from overlay keys, ignore repeated actions and preserve Option-copy behavior for files/video.
