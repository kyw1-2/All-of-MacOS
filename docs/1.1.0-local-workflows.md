# All of MacOS 1.1.0 (2026101502)

2026-10-15. CleanShot X·Paste 비교표에서 지적한 **로컬 기능**의 구현 변경이다. 클라우드 업로드, 계정, iCloud, 공유 Pinboard, 기기 간 동기화는 제외했다. 사용자의 요청에 따라 단위시험·회귀시험·수정 앱 실행·UI 비교·픽셀 비교·독립 검증은 수행하지 않는다. 배포 파일 생성에 필요한 컴파일과 코드 서명만 수행한다. 구현 사실과 작동 검증은 구분한다.

## 캡처

- `SelectionOverlay`: 영역·창·화면·스크롤·녹화·OCR를 같은 선택 오버레이에서 고르는 All-In-One 모드. 모드 전환과 키보드 처리, 모니터 사이를 가로지르는 전역 선택 좌표 공유, 세션 종료 시 키 모니터 정리.
- `ScrollingCaptureSession`: 수동 스크롤을 기본으로 시작하고 자동 스크롤, 방향, 일시정지/재개, 완료/취소, 실시간 축소 미리보기를 제공한다. 컨트롤 창과 테두리는 캡처에서 제외한다. 프레임 수·이미지 크기 한계에서는 일시정지하고 사용자에게 알린다.
- `ScrollingCaptureService`: 정지한 프레임의 중복 누적을 막고 고정 도구막대 영향을 줄이도록 내부 영역을 비교한다. 방향을 바꿔 되돌아가는 스크롤, 임의의 고정 요소·애니메이션·반복 무늬의 정확한 연결을 보장하지 않는다. 실제 앱별 성공률은 측정하지 않았다.
- `ScreenCaptureService`: 선택 영역과 교차하는 화면 조각을 공통 배율로 합성한다. 전체 화면의 디스플레이 로컬 원점과 이전 영역 경계 처리를 수정한다.
- `CaptureHistory`/`MediaHistoryOverlay`: 고정 상태를 보존하고 Pinned 필터를 연결한다. 개수 기준과 함께 1/7/14/30일 또는 기간 무제한 정책을 제공하며 고정 항목은 자동 정리에서 제외한다.

## 클립보드

- `ClipboardStackPasteMonitor`/`ClipboardPanel`: 스택 세션이 열려 있을 때 대상 앱의 ⌘V를 받아 다음 항목을 먼저 클립보드에 쓰고 대상 프로세스에 붙여넣기를 전달한다. 생성한 이벤트는 재수집하지 않으며 빠른 반복 입력을 직렬화한다. Shift-⌘V는 일반 텍스트로 처리한다. 대상 앱 변경·세션 종료 시 대기 작업을 중단한다. 대상 앱별 붙여넣기 소비 타이밍은 시험하지 않았다.
- `ClipboardStore`: Vision OCR로 이미지의 텍스트를 로컬 색인한다. 이미지를 편집하면 색인을 다시 만든다. 검색은 제목·내용·출처·파일 경로·이미지 OCR을 포함한다.
- `ClipboardSearchQuery`: 따옴표 구문, 제외어, `type:`, `from:`/`app:`, `board:`, `before:`, `after:`를 제공한다. 검색창에 최근 검색·자료형 제안과 색인 진행 상태를 표시한다.
- 삭제 복구와 ⌘Z, 이미지 주석 편집 후 원래 클립 갱신, 복수 파일 Quick Look 페이지 이동, 수집 일시정지 명령을 연결한다.
- Pinboard 항목은 기간·개수·전체 용량 정리에서 제외한다. 보존 기간 무제한과 50MB–1GB의 비고정 기록 용량 선택을 제공한다.
- `ClipboardArchiveEncryption`: 로그인 Keychain의 장치 전용 키로 AES-GCM 저장 파일을 암호화한다. 기존 JSON을 읽은 뒤 암호화 파일의 원자적 저장이 성공한 경우에만 이전 활성 JSON을 제거한다. 키 접근 또는 복호화 실패 시 저장을 차단하고 기존 파일을 보존한다. 별도로 만든 백업까지 자동으로 암호화하지는 않는다. 최초 사용 시 로그인 Keychain 접근이 필요할 수 있다.

## 녹화

- 시스템 오디오+마이크 선택, 별도 입력 트랙의 종료 시 믹싱. 마이크 경로는 macOS 15 이상이 필요하다. 믹싱 실패 시 두 오디오 트랙 원본을 보존한다.
- 일시정지/재개를 영상·음성·커서 시간축에 반영한다. HUD·메뉴·사용자 지정 전역 단축키·URL 명령으로 접근할 수 있다. 기본 일시정지 단축키는 ⌥⇧⌘Space이다.
- 여러 화면의 ScreenCaptureKit 스트림을 하나의 선택 영역으로 합성한다. 큰 영역은 긴 변 7,680픽셀까지 비례 축소한다.
- 카메라와 단축키/탐색키 표시를 최종 영상에 합성한다. 일반 입력 텍스트는 표시하지 않으며 Secure Input 상태에서는 키 표시를 억제한다. 카메라와 키 표시는 저장 후 독립 레이어로 제거하는 형식이 아니다.
- 2초 단위 MP4 fragment와 복구 저널을 작성한다. 시작 시 남아 있는 파일에 대해 복구·나중에·삭제 선택을 제공한다. 복구는 기록된 fragment와 AVFoundation이 읽을 수 있는 범위에 한정된다.
- 녹화 형식에 GIF를 추가한다. 최대 120초의 활성 녹화 후 GIF를 생성하며 MP4 원본도 남긴다. 편집기의 GIF 내보내기는 1–30fps, 최대 120초, 긴 변 960픽셀이다. GIF에는 음성이 없고 내보내기 실패 시 MP4를 유지한다.

## 주석·파일 연동

- `AnnotationProject`: 원본 PNG, crop, 객체, 스타일, 배경, 배율을 `.aomannotation`에 저장하고 다시 연다. AOM 고유 버전형 형식이며 CleanShot의 프로젝트와 호환된다고 주장하지 않는다.
- 프로젝트에는 가림 아래의 원본 이미지가 남으므로 공유할 때는 평면 이미지로 내보내도록 저장 대화상자에 표시한다. Solid Redact 출력은 불투명 덮기를 유지한다. 블러·픽셀화의 비식별화 안전성을 보증하지 않는다.
- 임의 색상, 글꼴·굵게·기울임·외곽선, 스타일 프리셋 저장/삭제를 추가한다. 텍스트 렌더링은 여러 줄 프레임을 지원한다.
- 이미지별 형식 선택 내보내기와 WebP를 추가한다. WebP는 배포 번들에 포함한 BSD 라이선스 libwebp/libsharpyuv를 사용하며 수신 Mac의 Homebrew에 의존하지 않는다.
- Finder에서 이미지/프로젝트 열기와 ‘Annotate with All of MacOS’ 서비스를 추가한다. 별도 Quick Look preview 확장은 AOM 프로젝트를 렌더링한다. macOS 확장 등록·Finder 표시·서비스 활성화는 실행 확인하지 않았다.
- 파일명 템플릿에 연·월·일·시·분·초·밀리초·요일·시간대·Unix 시간 토큰을 추가한다. 파일명 구분자 제한과 충돌 시 이름 변경은 유지한다.
- AOM URL에 `pause-recording`, `resume-recording`, `stop-recording`, `open-project?filepath=…`를 추가한다. 원본 앱 URL 스킴을 가로채지 않는다.

## 근거와 경계

사용자가 제공한 1.0.14 비교표, 현 저장소의 구현, 기존 조사 문서의 REA 증거를 작업 기준으로 사용했다. 이전 REA 자료는 CleanShot X 5.0.1/Paste 7.0.2 자료이므로 설치본 4.8.8/6.5.2의 동작 증거로 간주하지 않았다. 이번에는 원본 CleanShot 메뉴 접근만 시도했으며 기능 시나리오 실행 비교나 새로운 전체 역컴파일을 수행하지 않았다. 타사 바이너리·자산·비공개 클립보드 내용을 소스나 배포물에 넣지 않았다. 오픈소스 WebP 코덱의 라이선스·저자 고지는 번들에 포함한다.

기존 Quick Access·미리보기·드래그·기본 캡처 경로를 유지하면서 위 기능을 연결했다. 비교표의 ‘추가 검증 필요’ 항목을 시험 통과로 바꾸지 않는다. 클라우드를 제외한 전체 동작의 완전 동일성이나 일치율은 주장하지 않는다.

빌드: SwiftPM release → XPC/Quick Look 확장 컴파일 → 기존 AOM Dev 키로 코드 서명 → DMG 생성. AOM Dev는 기존 자체 서명이며 Apple Developer ID 공증이 아니다. 이 요청에서는 별도 서명 검증·DMG 검증·설치 후 실행을 하지 않는다. 커밋의 `[skip ci]`는 이번 변경의 자동 시험 실행을 생략하기 위한 것으로, 기존 CI 시험 단계를 삭제하지 않는다.
