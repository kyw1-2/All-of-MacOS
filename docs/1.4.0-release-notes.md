# All of MacOS 1.4.0 — Searchable Settings

Build `2026102102`.

## What's new

- **One searchable settings hub:** Settings categories now share a single scrollable view rather than separate panels.
- **Fast discovery:** Search matches setting titles, descriptions and keywords; the search control receives focus when Settings opens.
- **Persistent navigation:** The page title, search field and category chips stay visible while grouped preference cards scroll.
- **Immediate changes:** Controls write preferences directly without an additional Save or Apply step. A brief confirmation indicates that a change was stored.
- **Consistent controls:** Rounded setting cards combine an icon, label, explanation and control. Advanced gesture, shortcut, permission, backup and clipboard management interfaces open as sheets.
- **Preset migration:** A review-first import path for supported external gesture preset formats is available from the Automation section, subject to supported formats and trigger compatibility.

## Verification and limits

The release documentation reports a debug build and targeted settings-search tests on macOS 27.2 with Xcode 27.1, including empty queries, case normalization, Korean search keywords, multi-token matching and no-result cases.

This describes the implemented settings interface. It is not a blanket certification of runtime behavior, device coverage or appearance on every macOS configuration.
