# All of MacOS 1.4.0

Build `2026102102`.

## Settings rebuilt as one surface

The Settings window was an eight-section sidebar whose pages each scrolled
independently: you scrolled down to change a value, then back up to confirm what
you had done. 1.4.0 replaces that with a single searchable surface.

- **Search first.** Every setting has a title, a plain-language subtitle and
  keywords ("커서", "백업", "btt", "fps"). The search field has focus when the
  window opens and matches across all categories, so the usual path is
  `⌘,` → type → toggle.
- **One scroll, sticky controls.** Title, search and category chips stay pinned;
  only the setting cards scroll. Changing a category animates and scrolls that
  section to the top instead of reloading a new page.
- **Instant apply, no save button.** Every control writes straight to
  `UserDefaults` through a single binding helper and posts one change
  notification. A short "저장됨" indicator confirms the write; there is no
  Apply/OK step and nothing to re-open to verify.
- **Cards, not forms.** Rows are 56 pt tall with an icon, a title, one sentence
  of explanation and the control on the right, grouped into rounded cards per
  category. Long technical paragraphs moved into the advanced sheets.
- **Advanced work stays in place.** Gestures, shortcut recording, permissions,
  backups and clipboard storage open as sheets over the hub, so you keep your
  place in the settings list.
- **BTT preset import is one click** from Automation and reuses the existing
  review sheet that lists supported and skipped triggers before anything is
  added (disabled).

## Verification

- `swift build -c debug` and `swift test --filter SettingsSearchTests` on
  macOS 27.2 / Xcode 27.1.
- Search behaviour is unit-tested for empty queries, case folding, Korean
  keywords, multi-token AND matching and no-match.

## Scope

Static source change only. This release claims the settings layout and
immediate-apply behaviour changed; it does not claim runtime, performance or
visual equality with any third-party app.
