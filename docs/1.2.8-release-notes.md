# AOM 1.2.8 — A refreshed Mac workspace

2026-10-19 · build 2026101903 · based on 1.2.7 (`e90d3c9`).

## Design

- A clearer sidebar with a compact app/preset identity, SF Symbols, native selection and scope badges. Existing application/group navigation and keyboard commands remain available.
- Home puts four real actions up front: Capture Area, Capture Text, Record Screen and Clipboard. They fill four columns when space allows and two in a compact detail pane. Status, gesture shortcuts and recent items follow in an adaptive layout.
- Shared page headings, restrained accent colors, continuous 16-point surfaces and a subtle static canvas connect Capture, Clipboard, Window Tiling and Insights.
- The gesture table sits in an inset surface with its scope summary above it and a narrower, resizable native inspector. Sorting, filters, selection, workflow editing and context menus remain native.
- NavigationSplitView and the system toolbar own the current platform material on macOS 26+. The hosting window is made non-opaque when attached, so native behind-window materials can render. macOS 14–25 use a single legacy sidebar material. Reduce Transparency / Increase Contrast select an opaque sidebar/canvas fallback. No full-window custom glass shader or animated blur is added.

Design references (layout and material guidance, not copied code or assets):

- [Apple Materials HIG](https://developer.apple.com/design/human-interface-guidelines/materials): use materials to distinguish navigation from content.
- [Build an AppKit app with the new design, WWDC25](https://developer.apple.com/videos/play/wwdc2025/310/): native sidebar/toolbar, content hierarchy and system-owned chrome.
- [Shortcuts Gallery on Mac](https://support.apple.com/guide/shortcuts-mac/discover-shortcuts-in-the-gallery-apdd018638ca/mac): discoverable action tiles and organized navigation.
- [Raycast Settings](https://manual.raycast.com/settings): compact navigation and direct access to commands/preferences.

## Responsiveness

| Previous source behavior | New behavior |
| --- | --- |
| MainWindow observed GestureLog without reading its contents | Removes the subscription so gesture logging does not itself invalidate the whole main window |
| Home observed clipboard and capture history at the root | Those publications are confined to their sections; permission refreshes stay in the status section |
| Home decoded capture thumbnails while evaluating the overview | Shows lightweight capture metadata with the existing double-click annotation action; full previews remain in Capture Studio |
| Every sidebar scope badge scanned every trigger again | One linear aggregation supplies enabled/global/application/group counts, preserving group precedence and disabled-scope counts |
| Profile artwork was resolved on every sidebar evaluation | Resolution runs when a profile row appears or its bundle identity changes |
| Clipboard Studio scanned full text and counted every board during hover/search redraws | Reuses cancellable snapshot search, caches results by revision/filter and computes board counts on a worker |
| Clipboard Studio and Home wrote prepared clipboard payloads synchronously | Uses the asynchronous write path with the existing new-copy/edit/delete guards |
| Every SwiftUI material update reset AppKit effect properties | Set only changed material properties; window transparency config follows actual attachment/reattachment |

The canvas uses a static color gradient; action tiles and text/table surfaces have solid backgrounds. There are no new display-link loops, continuous effects or per-row backdrop blurs. Existing Reduce Motion handling remains in shared animations.

## Verification

- Focused tests: **13 passed**, including native material host reattachment, scope-badge parity on 10,000 gestures, clipboard cancellation/search protection and opt-in UI rendering.
- **18 fixture renders** cover all six main pages, light/dark Home and Gestures, the empty editor, a 1,040-point window, a high-contrast AppKit appearance and settings. Offscreen native vibrancy can produce incomplete sidebar/selection compositing; these images verify content layout and do not establish live glass rendering or GPU frame rate.
- A debug test aggregated all badges for 10,000 gestures in **4.63 ms** on this Mac. This isolates aggregation; it is not an end-to-end frame-time measurement.
- Full regression suite: **861 tests, zero failures, one opt-in rendering skip**. That rendering check passed separately above.
- Signed-bundle diagnostics, DMG digest/signature, live navigation checks and installation/state preservation are recorded in the GitHub release.

Native material rendering adapts to the OS, window activity, desktop and accessibility settings. Older supported OS versions are availability-guarded but were not physically tested here. No universal zero-lag or frame-rate claim is made. User presets, history and preference formats are unchanged.
