# AOM 1.0.8 — Capture and Studio editing

Build 2026101302. Continues `release/aom-studio-cursor-20261013` and preserves the owner's Quick Access Option-key policy changes.

## Changes

- Quick Access: double-click screenshots to annotate and recordings to open the video editor. Space still opens Quick Look. The recording context menu exposes Edit Recording directly.
- Preview cards reveal controls on hover; the two smallest sizes use a horizontal Copy/Save row to keep all controls inside the card. Recordings show a play affordance when not hovered.
- Annotation editor: compact utility row plus a scrollable tool strip, directly accessible undo/redo, and a window sized to the available screen instead of requiring 1120 points. Crop controls also remain reachable in a narrow window.
- Studio: edited live preview, scrollable settings on small screens, select a keyframe to load its controls, and undo the last zoom edit. Cursor dwell can generate editable zoom suggestions; this is AOM's own heuristic, not CleanShot's scene-analysis model.
- Source-time keyframes remain anchored when trim bounds change. MP4, GIF and preview use the same source-time effects. Regular trims composite separately recorded cursors for standalone playback.
- Cursor position follows the same zoom and background inset as the video. Visibility transitions prevent a pointer outside the recording area from remaining on screen; samples use the video host clock and actual clipped capture rectangle.
- Recording finalization blocks overlapping starts, and callbacks are bound to their originating stream. Sidecar reads are bounded before decoding.
