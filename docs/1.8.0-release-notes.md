# All of MacOS 1.8.0

Build `2026102303`.

## Glass, the Apple way

1.7.0 established the card grid. 1.8.0 makes those cards glass and lets the window
breathe, following Apple's vibrancy guidance rather than a decorative blur.

- **Ambient window** — a static light base plus three large, heavily blurred colour
  fields (blue, indigo, cyan). No animation, no per-frame blur cost; it exists so the
  material has real colour to refract.
- **Glass cards** — `.ultraThinMaterial` under a 50% white film (30% black in dark
  mode), a specular edge that runs bright to transparent along the top-left diagonal,
  and a soft drop shadow. Same modifier for `AOMCard`, `AOMSurface`, tiles and groups,
  so every page inherits it.
- **Glass top bar** — the 64 pt navigation bar floats on material over the ambient
  background; the page canvas continues underneath.
- **Readability** — text sits on a white/black film over the material, so contrast does
  not depend on the wallpaper. Increase Contrast swaps the specular edge for a solid
  border.

## Text into password fields

macOS enables **Secure Event Input** while a password field has focus. Every posted
`CGEvent` — including virtual keycodes — is discarded, which is why the ⌥P text action
silently produced nothing.

- New `SecureTextPaste` delivers through the general pasteboard with ⌘V, which secure
  fields still accept.
- The temporary item is tagged `org.nspasteboard.ConcealedType` and `…TransientType`, so
  it never enters AOM's clipboard history or another manager's.
- The previous clipboard contents are snapshotted and restored after 0.7 s; the restore
  is skipped if another app wrote to the pasteboard meanwhile.
- The payload is never logged; failures report that the control rejected paste.

## One language

The interface is English end to end. Home, shell and Settings copy were translated; the
remaining Korean strings are bilingual search keywords and heuristics, deliberately kept
so Korean queries still match.

## 1.8.1 follow-up

The window canvas is now fully opaque. With a colourful desktop wallpaper the
semi-transparent base tinted the navigation bar and page background, which read as a
muddy grey-lavender. Glass now refracts AOM's own ambient field only — the way Apple's
vibrancy is meant to work inside a window — and the ambient colours were lowered
(14/12/8% light, 26/22/14% dark).
