# All of MacOS 1.0.2 — Quick Access Overlay rebuild

## Reference features and implemented behavior

Sources reviewed:
- https://cleanshot.com/features (Quick Access Overlay feature list and product screenshots)
- https://cleanshot.com/changelog (overlay keyboard controls, Save As, temporary hide, OCR, 1×, flip, print)
- https://cleanshot.com/docs-api (restore last closed, external capture import)
- https://www.imore.com/cleanshot-x-gains-new-keyboard-shortcuts-quick-access-overlay-more

Implementation is independent SwiftUI/AppKit, inspired by functional specifications. Proprietary icons, artwork, project files, and cloud infrastructure were not copied.

| Quick Access behavior | All of MacOS 1.0.2 |
|---|---|
| Compact thumbnail, central Copy/Save, corner Pin/Edit/Close and More | Added native SwiftUI panel layout |
| Native file drag to Finder or another app | AppKit dragging session provides file URL |
| Close after *successful* drag (not at drag start) | AppKit NSDraggingSource completion + configurable setting |
| Keep overlay open while clicking other applications | Removed global outside-click monitors |
| Copy, Save, Save As, Annotate, Pin, OCR, QR | Implemented; Save As selectable/Option-save |
| File info, OS Share sheet, Open With, Print | Implemented; OS share destinations only |
| Copy Retina 1×, flip, rotate left | Non-destructive transformed PNG to clipboard |
| Move to Trash | NSWorkspace.recycle; errors retain the overlay and history entry |
| Zoomed preview + video preview/editor | Independent resizable image/video window, video edit sheet |
| Restore recently closed thumbnail | Capture menu restore action, 20 item bounded closed stack |
| Multiple simultaneous thumbnails | Up to three, automatically repositioned by corner |
| Sizes, corners, active display, configurable auto-close | Five sizes, four corners, interval/never/after drag |
| Hover pauses timer, dragged file pauses timer | Added pause/resume with remaining time |
| Horizontal trackpad swipe to dismiss, temporary slide-down hide | Native horizontal gesture and animated hide |
| Shortcuts Cmd-C/S/E/P/W, Return, Space, Esc | Scoped to focused overlay only; no global shortcut stealing |
| Screenshot versus MP4 actions | Contextual actions; MP4 opens resizable player and edit/export view |
| CleanShot Cloud upload/URL, protected sharing, cloud comments | Not implemented. Native macOS Share sheet is available, **not** a proprietary cloud clone |
| CleanShot editable project file, third-party extension/API | Not implemented |

## Preserved behavior and limitations

- No changes to gestures, saved preset mappings, clipboard data, or upstream GTT files.
- When a capture is explicitly moved to Trash, the original saved file is recycled, not silently permanently deleted.
- New history/Quick Access windows are local and use the user's app-specific storage. No cloud upload.
- Actual cross-app drag/drop, hover-animation fidelity, popup keyboard focus on arbitrary desktops, screen permissions and external-display positioning require interactive macOS QA. Pure policy tests cannot prove visual 99% equivalence.
- The standalone AOM Dev certificate is not yet a valid Code Signing identity on the user's Mac. Do not misrepresent an ad-hoc CI artifact as AOM Dev signed.
