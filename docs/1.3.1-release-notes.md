# All of MacOS 1.3.1

Build `2026102101`.

## What changed

- **Capture visibility now applies to every AOM window.** The "Show in screen capture"
  switch used to affect clipboard surfaces only (panel, stack, detached preview, colour
  panel, text editor). It now also covers the annotation editor, the recording export
  editor, the expanded Quick Access preview, floating menu panels and the floating-menu
  editor. With the switch off the whole AOM UI stays out of screen recordings and shared
  screens; with it on (the default) behaviour is unchanged.
- `NSWindow.applyCaptureVisibility(_:)` and `applyCaptureVisibilityPreference()` centralise
  the policy, so future windows opt in with one call.
- Tests: `ClipboardLocalGapTests` covers both helper states and the preference default.

## Verification

- `swift build -c debug` and `swift test --filter ClipboardLocalGapTests` on macOS 27.2 /
  Xcode 27.1.
