# All of MacOS 1.3.1 — Consistent Capture Visibility

Build `2026102101`.

## Highlights
- Expanded the existing screen-capture visibility preference beyond clipboard windows to annotation, recording export, expanded previews and floating control windows.
- Centralized window visibility configuration so newly created AOM windows can apply the same preference consistently.
- Preserved the default visible state for existing users.

## Verification and limits
Documentation reports a debug build and focused `ClipboardLocalGapTests` on macOS 27.2 / Xcode 27.1. Screen-capture exclusion depends on the macOS implementation and the capturing application; the preference is not a universal guarantee.
