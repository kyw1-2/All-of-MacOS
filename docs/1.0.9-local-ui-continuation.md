# AOM 1.0.9 — Local UI continuation

Build 2026101303, continuing merged PR #4 on main.

## Changes

- Clipboard: centered capsule search, filter popover with type/app/date chips, compact pinboard icons during search, pinboard color controls, and a fixed-width overflow menu.
- Clipboard input: type to search, Command-F to focus search or open filters, Tab/Down from search to cards, anchored Shift selection, Command-number badges, and copy all selected entries. Search spans history while a query is present.
- Paste Stack: separate floating queue with captured items, reverse order, remove/move-to-top, collecting/pause, and paste-next. The queue keeps the destination app's keyboard focus and stops collecting when closed.
- Annotation: a single toolbar with crop/add/background, the main segmented tool strip, color/thickness, canvas lock and Save as. Resize, rotate/flip, OCR highlight, blur/redact and layer actions remain in More. Horizontal scrolling preserves access on smaller displays.
- Expanded capture preview: unified window chrome, capsule Annotate/Save as controls, bottom zoom, Drag Me, pin/share/copy, shared with history preview.
- Quick Access: hide the menu chevron and constrain capsule action widths to the compact thumbnail area. Existing cloud capture/Studio and Option-key policies remain.
