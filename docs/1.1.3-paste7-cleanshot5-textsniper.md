## TextSniper → Capture Text 대체

REA 결과: TextSniper 1.12.0은 번들 OCR 모델이 없고 Vision/VisionKit만 쓴다. 비결은 (1) 모든 지원 언어를 주 언어 우선으로 넘기고 (2) 한·중·일 주 언어일 때 VisionKit Live Text(`ImageAnalyzer`)로 전환하는 것. 이 Mac에서 측정하니 Vision 한 번은 첫 언어의 문자 체계만 제대로 읽어 혼합 문장을 깨뜨렸다.
AOM 엔진: 자동 감지 1차 → 존재하는 문자 체계별 Vision 패스 → 어두운 화면 반전 패스, 작은 글자 업스케일 → Live Text 동시 실행 → 토큰 단위 신뢰도 투표 융합 → 불일치 영역 Live Text 재판독. 열·표 감지, 문단 재배치, 하이픈 결합, CJK 띄어쓰기, 링크, QR/바코드. 설정: 언어 우선순위(자동/순서 지정), 엔진, 언어 보정, 사용자 단어, 줄바꿈 유지, 누적 클립보드, 소리, 결과 HUD(복사·편집·읽기·공유), 음성 읽기, 단축키(⇧⌘2, 줄바꿈 반전 ⌥⇧⌘2, 클립보드 이미지, QR). Quick Access·핀·스마트 하이라이터·클립보드 이미지 검색 색인도 같은 엔진을 쓴다.
