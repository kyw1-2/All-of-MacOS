# AOM 1.0.10 — Responsive clipboard and top capture shelf

- Clipboard selection is observed on native mouse-down without waiting for SwiftUI double-click recognition. The existing double-click copy, drag and context-menu routes remain.
- Pointer selection no longer recenters the carousel; keyboard arrow navigation still reveals its destination. Pinboard changes no longer animate an entire carousel rebuild.
- Clipboard image previews and pixel dimensions are created on a background queue with ImageIO downsampling, then retained in a bounded 48 MiB thumbnail cache. Rendering selection no longer decodes full-size images.
- Capture history is a full-width horizontal shelf at the top of the active display. Search, capture-type tabs, selection actions, preview, edit and drag remain available.
- Each shelf is limited to half of the display's usable height with edge padding and a gap, including clipboard resizing. Clipboard history remains at the bottom.

The owner requested no tests or UI validation. Only release compilation/signing and distribution were performed; no measured latency improvement or runtime parity is asserted.
