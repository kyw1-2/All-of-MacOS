# All of MacOS 1.1.5 (2026101704)

BTT, CleanShot X, and Paste local native parity improvements and bug fixes based on REA inspection of AOM 1.1.4.

## Key Changes

### BetterTouchTool (BTT) Parity Fixes
- **System Dark Mode**: Replaced local-only `NSApp.appearance` toggle with macOS system-wide AppleScript (`tell application "System Events" to tell appearance preferences to set dark mode to not dark mode`).
- **Do Not Disturb (Focus)**: Replaced unhandled error stub with Shortcuts CLI integration (`/usr/bin/shortcuts run "Toggle Focus"` / localized).
- **Lock Screen**: Replaced `ScreenSaverEngine.app` launcher with native `SACLockScreenImmediate` via `login.framework` and synthetic ⌃⌘Q fallback for immediate secure lock.
- **Named Trigger URL Scheme**: Supported `aom://trigger?name=<name>` and `aom://trigger_named?trigger_name=<name>` deep links for invocation from Raycast, Alfred, and Shortcuts.

### CleanShot X 5.0.1 Parity Fixes
- **Spotlight Annotation Tool**: Added `SpotlightShape` picker (Rectangle vs Ellipse) and dimming opacity slider (0.2...0.95), matching CleanShot X. Canvas preview and raster rendering now accurately cut out rectangular or elliptical highlights.
- **Counter Tool Sequence Styles**: Added 4 sequence formatting styles (`1, 2, 3`, `A, B, C`, `a, b, c`, and `I, II, III`) with automatic reformatting upon style change.

### Paste 7.0.2 Parity Fixes
- **Timed Clipboard Pause**: Added `pause(for: Int)`, `pauseRemainingSeconds`, and `resume()` to `ClipboardStore`, supporting timed auto-resuming (5m, 15m, 1h, 8h).
- **Ignored Apps Parsing**: Trimmed whitespace and filtered empty lines when updating `ignoredApps` to avoid unintended empty string bundle ID matching.

### Layout & Quality
- **Responsive Layout**: Replaced hardcoded minimum window width of 1300pt with 1040pt and enabled `@AppStorage` persistence for side console / live touch panels, allowing comfortable use on 13"/14" MacBook displays.
- **Text Recognition Classifier**: Resolved dictionary hash non-determinism in `TextScriptClassifier.dominantScript` with explicit language tie-breaking.
- **Regression Suite**: Added `AOM115ParityTests.swift` covering all new features; full test suite passes with 768 tests (0 failures).
