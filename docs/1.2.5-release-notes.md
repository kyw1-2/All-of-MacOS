# All of MacOS 1.2.5 — Clipboard, Capture and Automation Responsiveness

Build `2026101805`.

## Highlights
- Reduced clipboard polling from 600 ms to 150 ms and moved copy classification and hashing away from encrypted history persistence.
- Improved direct insertion into target processes, rich-text ingestion, animated image handling and date-based history search.
- Ordered capture and OCR automation steps after their actual output becomes available.
- Moved screenshot encoding and export work off the main UI thread, added collision-safe saving and preserved recoverable previews on failure.
- Tightened cancellation behavior, trigger invocation policies and cleanup of delayed automation work.

## Verification and limits
For the initial 1.2.5 release, automated tests, performance benchmarks, hands-on UI tests and independent verification were **not run** at the user's request; compilation, local signing and packaging alone were completed. This update does not establish universal input or device compatibility, or overall performance improvement.

A distinct 1.2.5 hotfix source revision addressed encrypted activity-log migration, archive recovery, automation-scope failures and image-memory handling; consult its separate release tag for verification and artifact details. The app uses the existing self-signed development identity, not Apple notarization.
