# All of MacOS 1.2.2 (2026101802)

A native main window, a clipboard shelf that opens and closes cleanly, and a sweep of small functional fixes.

## Main window

Rebuilt around Apple's own Mac app structure: a full-height source list, flat content, an optional trailing inspector, and commands in the toolbar. Decorative banners and nested cards were removed.

- **Home** (⌘1): grouped, System Settings–style rows.
  - Status: Automation, Drag to Snap, Clipboard History, Permissions and shortcut conflicts, each with an inline switch or fix button.
  - Your gestures with on/off switches; click a row to open it.
  - Recent clipboard items; double-click a row to copy.
  - Recent capture thumbnails; double-click to annotate.
  - Capture Area, Capture Text, Record and Clipboard sit in the window toolbar.
- **Gestures**: a sortable table (On, Name, Trigger, Actions, Type) instead of tiles.
  - Checkboxes enable or disable gestures inline, and a fired gesture flashes its row.
  - Selecting a row shows its actions, details and sensitivity in a native inspector that can be toggled from the toolbar.
  - Type filter, scope, search and New Gesture are toolbar items. ⌫ deletes after confirmation.
- **Sidebar**: colour icon tiles in grouped sections (Automation, Media, Applications, Activation Groups; the last two collapse). ⌘1–⌘6 switch pages from the View menu.
- **Page headers** are a plain status line with the page's controls. The title is the window title.

## Clipboard shelf (⇧⌘V)

- **Another app owned the shortcut.** Paste 7 (running here) registers ⇧⌘V as a system hotkey. macOS delivers that key to Paste before any other app sees it, so Paste's window flashed and the AOM shelf often did not open. AOM now detects this:
  - at launch and whenever Paste starts, an alert offers "Use ⌥⌘V for All of MacOS", "Quit Paste" or "Keep Both";
  - Home and Clipboard settings show the same conflict.
- **No stray frame on another display.** The shelf now fades in and out in place, composited by the WindowServer. Before, it slid in from beneath the screen edge, which drew it briefly on a display arranged below, and the frame animation ran on the main thread, so any other work made it stutter. The system zoom animation is off, and a late completion can no longer leave the shelf half-faded.
- **Opening** no longer makes AppKit search SwiftUI's focus graph, which cost about 200 ms per open.
- **Double-click paste** uses one tap recognizer. Copying no longer reorders the history while the shelf is visible. Cards re-render only when their own content changes.
- **Smaller fixes:**
  - all state resets run after the fade-out;
  - sounds play off the main thread;
  - paste-log classification runs in the background;
  - the context menu and drag no longer scan or decode on the main thread;
  - ⌘A sets the selection anchor;
  - closing a preview returns focus to the shelf.

## Functional fixes

- `aom://` links no longer open the Workflow Variables window.
- **Force Click**: a new Settings › Gestures section turns it on and sets the threshold. Previously no UI could enable it.
- **Quit / Hide / Toggle Application** accept an app name or path, not only a bundle ID.
- **Open URL** accepts addresses without a scheme.
- **Toggle Dark Mode** no longer pins AOM's own appearance.
- **Double Click** sends click numbers 1 then 2.
- **Pause/Resume Recording** takes its shortcut only while recording.
- **Menu bar**:
  - "Restart" lost its ⌘R shortcut;
  - "…and N more" opens the main window.
- **Microphone permission** is required for "Computer + Microphone" recordings.
- **Annotation crop button** exits crop mode.
- **About** shows the real version and build.
- Removed unused legacy toolbar views and a non-functional "Master Preset" item.

## Verification

- 783 tests pass.
- Checked on this Mac (macOS 27.2) with synthetic input that presses real modifier keys:
  - 6 of 6 ⇧⌘V open/Esc cycles opened and closed with Paste and Raycast quit, and the shelf was only ever seen at its final frame on the display under the pointer;
  - double-click paste dismissed the shelf in about 0.3 s, three times.
- Raycast and Paste were relaunched after the test.
- Real trackpad and keyboard use was not exercised.
