# All of MacOS 1.2.2 (2026101801)

A rebuilt main window, a lag-free clipboard shelf double-click, and a sweep of small functional fixes.

## Main window

Patterned on Apple's own Mac apps: a System Settings–style source list, Shortcuts-style tiles, and a native inspector.

- **New Home page** (⌘1): a gradient hero with greeting, live counts, an Automation On/Paused switch and one-click capture/clipboard actions (Liquid Glass on macOS 26+), plus cards for Gestures, Clipboard, Capture Studio, Window Tiling, Insights and Permissions. Each card links to its page, and missing permissions show as a banner with an "Open System Settings" button.
- **Sidebar**: colour icon tiles, grouped sections (Automation, Media, Applications, Activation Groups; the last two collapse), an app identity header with the version, and gesture counts. ⌘1–⌘6 switch pages from the View menu.
- **Gestures**: a gallery of gradient tiles grouped by trigger type, with category chips and counts, enable switches on each tile, and fired gestures flashing green. Click a tile to open the editor, which has a large editable title, the action sequence and a native inspector (toggle it from the toolbar). ⌘[ or Esc goes back. The classic list + canvas layout is still available from the toolbar Gallery/List switch.
- **Every page** has a tinted hero header.

## Clipboard shelf (⇧⌘V)

Measured on 1.2.1: some double-click pastes held the shelf on screen for about 3 s, and every open cost about 300 ms on the main thread.

- Opening: the shelf now has a lightweight first responder, so AppKit no longer walks the SwiftUI focus graph each time it is ordered front (about 200 ms per open).
- One tap recognizer reads the click count. Previously the pasting click also re-selected the card, and toggled ⌘/⇧ selections.
- Copy and paste no longer reorder the history while the shelf is visible; the reorder is applied after it closes. Copying is a single published change, not one per item.
- Cards re-render only when their own content changes, not when the store revision bumps.
- All state resets (selection, suggestions, preview) run after the slide-out finishes.
- Sounds play on a background queue through prepared `AVAudioPlayer`s instead of `NSSound`, whose first play blocked the main thread.
- Paste-log classification runs off the main thread. FoundationModels availability is cached.
- The card context menu no longer scans the whole history on every render. Dragging an image card no longer decodes it on the main thread.
- ⌘A sets the selection anchor. Closing a preview by clicking outside returns keyboard focus to the shelf.

## Functional fixes (full audit)

- Force Click: new Settings › Gestures section to enable it and set the threshold. Before, nothing in the UI could turn Force Click triggers on.
- Quit / Hide / Toggle Application now work with an app name or path, not only a bundle ID.
- Open URL accepts addresses without a scheme ("apple.com" → https).
- Toggle Dark Mode no longer pins AOM's own appearance, so "Follow System" keeps working.
- Double Click action: the presses carry click numbers 1 then 2, like real hardware.
- The Pause/Resume Recording shortcut only takes its key while recording.
- The menu bar "Restart" item no longer has a ⌘R equivalent.
- The menu bar "…and N more" gestures item opens the main window.
- The microphone permission is required for "Computer + Microphone" recordings too.
- The Annotation crop toolbar's crop button exits crop mode instead of doing nothing.
- About shows the real version and build number.
- Removed unused legacy toolbar views and a non-functional "Master Preset" menu item.

## Verification limits

Live QA used synthetic input on one Mac (macOS 27.2). Some synthetic clicks don't reach the window, which looks like a test-harness limit; real trackpad input was not exercised.
