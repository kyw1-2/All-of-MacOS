# AOM design overhaul — references and decisions (2026-10-24)

The overhaul reworks every main-window page, Settings, the command palette, first run, the menu bar menu and the floating capture/clipboard surfaces into one grammar. Behaviour, shortcuts, stored data and settings keys are unchanged; only presentation and navigation moved.

Research covered 80+ sources: 44 Apple references (HIG, WWDC25/26, first-party apps), 32 design-acclaimed Mac apps and a focused pass over Paste, CleanShot X and BetterTouchTool. Pages were read as text; app UIs were not run. Where a reference is a recommendation rather than a stated rule it is marked as such in the source notes.

## The grammar

| Rule | Where it comes from |
|---|---|
| The shell is the system's: `NavigationSplitView` sidebar and toolbar, no AOM window material, page title in the toolbar, never repeated in content | HIG Sidebars, Toolbars, Windows; WWDC25 "Build a SwiftUI app with the new design" (323) |
| Two layers: Liquid Glass only on functional chrome (sidebar, toolbar, palette, HUDs, floating panels); content is a calm canvas with white cards | HIG Materials; WWDC25 "Meet Liquid Glass" (219); Apple "Adopting Liquid Glass" |
| One floating material for every panel (`aomFloatingSurface`: glass on macOS 26+, popover/HUD material before, opaque under Reduce Transparency / Increase Contrast) | Paste 6, CleanShot X 4.8.5 and BTT 6.150 Tahoe redesigns |
| Colour for meaning only: state, selection, the one primary action; monochrome glyphs elsewhere | HIG Color; Linear 2026 refresh ("don't compete for attention") |
| macOS text styles: Title 1 22, Title 2 17, Title 3 15, Headline/Body 13, caption 11.5, nothing under 10 | HIG Typography |
| Concentric radii by role: panel 18, HUD 16, card 12, tile 9, well 7, control 6 (`AOMRadius`) | WWDC25 "Get to know the new design system" (356) |
| Every section page = one header row in the toolbar + a scope bar + cards on the canvas; same places for search, view options and the primary action | Linear 2026 (same header slots everywhere); Figma UI3 (one skeleton) |
| Filters show their counts and hide inputs nothing uses | Raycast ⌘P filters, Keyboard Maestro smart groups, Paste filter chips |

## The binary now declares its real SDK

SwiftPM recorded the deployment target (macOS 14) as the build SDK, so macOS 26/27 ran AOM in its compatibility appearance: no Liquid Glass sidebar, toolbar or controls, whatever the code asked for. `build-and-sign.sh` and `bundle.sh` now stamp the SDK the binary was compiled with (`vtool -set-build-version macos 14.0 <sdk>`); the minimum system stays 14.0. This is the single largest visual change and also enables AppKit's newer linked-on behaviours.

## Surfaces

| Surface | Before | After | Main references |
|---|---|---|---|
| Sidebar | Brand block, search, places | Search, places with live state badges (Paused, REC), engine switch; the brand block went to the window title | HIG Sidebars (no branding, accent icons); Tower sidebar badges |
| Workspace | Greeting, three launch tiles, automation list, recent column | Notices only when something needs you (incl. a running recording), then one card per tool with its live state and everyday action: capture modes + latest shots, newest clipboard items + Open Shelf/Pause, pinned or recent automations, snap zones as miniature layouts + Drag to Snap | Things "Today"; CleanMyMac tool tiles; Raycast root favourites; WWDC25 "Design foundations" (359) |
| Automation | Heading + icon-only segmented filter | Labelled input chips with counts (unused inputs hidden); editor Title 1 name, quieter When card with "Edit Input", "Then — N steps, in order", Options as a card | Keyboard Maestro and Hazel rule editors; Apple Shortcuts; Raycast filters |
| Window Tiling | "Arrange your space" hero, desk mock, text chips | Preview card (the layout under the pointer fills a miniature screen), gallery of miniature layout diagrams, Drag to Snap card, Zones & Layouts card | Swish, Rectangle Pro, Moom, Loop previews; macOS tiling menu |
| Capture | Three launch tiles + "Your captures" heading | One mode bar in CleanShot's order (All-In-One … QR Code) with shortcuts, scope bar with counts, S/M/L thumbnail density | CleanShot All-In-One; system screenshot toolbar (⇧⌘5); Bear/Nova density |
| Clipboard | "Your clipboard" hero + filled chips | Pinboard chips as the page's own navigation, paused state in the bar, Pause/Erase in More, two-line list rows of a fixed height | Paste pinboards; Raycast clipboard; Bear list + preview |
| Insights | Edge-to-edge strip and columns | Figures card, Most Used, Inputs and Configuration cards on the canvas | CleanMyMac My Activity; Ivory statistics |
| Settings | Custom sidebar, row cards without groups | System Settings sidebar (coloured squircles, search on top), titled groups per pane, segmented choices for 2–4 short options, clicking a switch's label flips it, new Shortcuts pane, Permissions pane with live status inline, a row into every capture option | System Settings; Raycast settings (search, shortcuts pane); Keyboard Maestro security pane; CleanShot 5 settings critique (unsung.aresluna.org) |
| Command palette | Material card | Shared glass panel, larger search, result count, glyph wells, uppercase section labels, action bar | Raycast v2 root search and action panel; Superhuman command palette essay; Spotlight on macOS 26 |
| First run | Seven coach marks describing the 1.x interface | Three skippable steps: the four tools, the access they need with live status and a reason, the global shortcuts and the menu bar switch | HIG Onboarding; Nova setup assistant; Paste first launch |
| Menu bar menu | Version header, toggles, one Capture submenu | Sections Capture / Clipboard / Automation, the everyday capture modes at the top level, every capture tool one level down, toggles with state, diagnostics under More | HIG Menu bar extras and Menus; CleanShot X menu (capture first); Klack footer |
| Floating surfaces | Seven different materials | Quick Access card, capture history, Paste Stack, recording bar, All-In-One toolbar and ratio list, scrolling capture panel, text-capture HUD and the palette share `aomFloatingSurface` | Paste 6, CleanShot 4.8.5, BTT 6 on Tahoe; HIG Panels |

## Not changed, on purpose

- The clipboard shelf keeps its Paste-matched geometry (tested 280/175/482 pt heights, r26 glass) — it already used Liquid Glass.
- The Gesture HUD keeps its dark OSD look and the user's background-opacity setting; its white text needs the dark material.
- The Annotate editor and recording editor keep their layouts; on macOS 26+ they pick up the system controls, and the Annotate footer moved clear of the larger window corners.
- CleanShot-ordered menus (`CaptureMenuCommand.layout`, `QuickAccessMenuCommand.layout`) and every user-visible command title are unchanged.
