# AOM 3.3.0 — UI/UX finishing pass: reference review

Reviewed 2026-10-28. This pass consulted **86 new reference documents**. None of them was used in the earlier rounds: 36 in `ux-reference-review-20261027.md`, plus the sources listed in `ui-liquid-glass-3.1.0.md` and `design-overhaul-20261024.md`. Every page in the table was opened. Apple HIG and developer pages render with JavaScript, so their text was read from the matching DocC JSON endpoints, but the links point to the normal pages. All takeaways are paraphrased.

Fix IDs map each takeaway to a change listed under *Applied*. A reference can support a decision without causing a code change of its own. Web guidance (WCAG, design systems) was adapted to native macOS rather than copied.

## Not done, on purpose

- **Re-tokenising the Automation editor.** ConfigurationPanel, TriggerListPanel and ActionListPanel hold about 86 numeric paddings and 23 fixed fonts. Reworking them is a separate pass with its own screenshots, because it would change the editor's density everywhere at once.
- **Migrating the spacing scale.** The guide proposes 4/8/12/16/24/32; the code uses 4/7/10/13/18/24. Changing it would move every page by a few points, so it needs before-and-after review on its own.
- **`AOMDesign.tileRadius`.** It stays the card radius. It is used for full-size clipboard and capture cards, where 12 pt is the intended radius.

## Verification limits

The pages were rendered in an isolated preview build (`com.kyw.allofmacos.preview`, separate data directory) in light and dark. Increase Contrast, Differentiate Without Color and Reduce Motion behaviour was reviewed in code, but not toggled at the system level during this session. The trackpad snap's recognizer, geometry, history, anchoring and readiness parsing are unit-tested. Live trackpad, overlay and Accessibility commits were not exercised from the build session.
