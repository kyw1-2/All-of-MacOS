# All of MacOS 1.7.0

Build `2026102302`.

## Why this release exists

1.6.0 changed the colours but kept the same skeleton: a permanent left rail plus a page
header. This release changes the skeleton, informed by current interface work
(bento grids, calm low-stimulus surfaces, compact top navigation):

- Bento grid layouts — varied card sizes, one job per card, rhythm instead of uniform tiles.
- Calm, low-stimulus UI — fewer competing elements, softer contrast, generous spacing.
- Compact, receding navigation — dim the chrome, let the page own the window.
- Motion as feedback — hover lift and short spring transitions, disabled under Reduce Motion.

## What changed

### Navigation

- The 236 pt left rail is gone. A single 64 pt top bar holds the product mark (with a live
  automation dot), a pill tab group, the app/group scope picker, ⌘K search, the gradient
  Capture menu and an overflow menu (diagnostics, settings, tour).
- Tabs are compact pills inside a tinted container; the selected pill is white with a
  small shadow. Below 1120 pt width the labels drop and only icons remain.
- Settings, tour and diagnostics no longer consume permanent screen space.

### Home

- Bento grid: a 208 pt gradient hero (greeting, status, two CTAs) beside a 300 pt summary
  card; four 74 pt quick actions; three 84 pt metric cards; then gestures, captures,
  clipboard and system status as 24 pt cards.
- Collapses to one column under 1000 pt; quick actions go 2×2.

### Surfaces

- Warm neutral canvas (`#F7F6F3`, dark `#161614`) replacing the cool grey, white cards,
  22–26 pt radii, softer hairlines, hover lift on interactive cards.
- Hero gradient (`#2F6AFF` → `#6753E6`) is the single saturated surface; everything else
  stays quiet.

### Motion

- Spring hover lift, 0.18 s tab transitions, all routed through `AOMDesign.animation`
  and `AOMLift`, which honour Reduce Motion.

## Verification

- `swift build -c debug`, `swift test -j 2` (932 tests).
- Release build through `build-and-sign.sh`, AOM Dev identity, installed to /Applications.

## Scope

Source-level redesign of window chrome, home layout and visual tokens. Claims do not
extend to pixel equality with any third-party product.
