# All of MacOS 1.6.0

Build `2026102104`.

## One visual language

1.4.0 rebuilt Settings and 1.5.0 rebuilt the window shell, but both kept the macOS
System Settings idiom: 13 pt rows, hairline borders, system material bars and dense
list groups. 1.6.0 replaces that idiom app-wide with a consumer-app language.

### Tokens

- **Canvas** — flat light grey (`#F2F4F6`), near-black in dark mode. The gradient wash
  and system material backdrops are gone, so pages stop shifting colour with the
  desktop behind them.
- **Cards** — pure white, 20 pt continuous corners, no borders, one soft shadow
  (`.aomCard()` / `.aomSurface()`). Dark mode uses `#1B1C21`.
- **Type** — 34 pt display, 28 pt page title, 23 pt window title, 17 pt section
  heading, 14 pt row label, 12.5 pt caption. Hierarchy comes from weight and size
  instead of separators.
- **Accent** — one vivid blue (`#3182F6`) for the default accent, primary buttons,
  selection and links. `AOMTheme.blue` is shared by the shell, home and Settings.
- **Controls** — `AOMFilledButtonStyle` (48 pt tall, 14 pt radius, full width),
  `AOMTintedButtonStyle`, `AOMChip`.

### Where it shows

- **Sidebar** — transparent on the canvas, 42 pt rows, selected row becomes a floating
  white card with a shadow instead of a tinted rectangle. No vertical rule between
  rail and content.
- **Top bar** — 76 pt, 23 pt page title, 34 pt search / capture / diagnostics controls
  on white pills. No `.bar` material.
- **Home** — 34 pt greeting, 100 pt primary action card in blue with a coloured
  shadow, 62 pt secondary actions, 74 pt metric cards with 24 pt numbers, and white
  grouped cards for status, clipboard, captures and gestures.
- **Settings** — 28 pt title, 36 pt capsule chips (selected chip is blue with a glow),
  white 20 pt cards, 64 pt rows with 40 pt icon tiles.
- **Every other tab** — inherits the canvas, card and type changes through the shared
  tokens; no page keeps a bordered system-style container.

## Verification

- Release build through `build-and-sign.sh` (AOM Dev identity).
