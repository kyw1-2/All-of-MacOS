# All of MacOS 1.0.5 — Paste-inspired clipboard interface

Reference: https://pasteapp.io/help/paste-on-mac and https://pasteapp.io/help/organize-with-pinboards

## Scope
Redesign only the clipboard history interface. Original SwiftUI and AppKit code, no copied proprietary artwork, branding or assets.

- Bottom-docked translucent timeline with horizontal, content-focused cards.
- Distinct color headers for Text (coral), Link (green), Image (blue), File (blue), Color (violet); source app icon and relative timestamp.
- Card image/file/link/text previews and compact footer title with inline rename.
- Search + colorful pinboard tabs with drag-to-pin; type/source/time filter menus.
- Height-resize grip with persisted height (AOMClipboardPanelHeight), compact card mode below 180 pt of available timeline space.
- New pinboards support six configurable colors.
- Command-N creates a reusable text item; Shift-Command-N creates a new pinboard. Command-C copies selected, Command-E edits text, Command-R renames. Search Return selects first result.
- Existing plain-text/rich-text persistence, history exclusions, deduplication, existing saved board IDs, direct paste keyboard path, and double-click-to-copy semantics preserved.
- Clipboard UI does not read user information from other services and does not upload data.

## Validation
A new clipboard UI storage integration test checks new item persistence, source clipboard untouched, colored board reload, pin/unpin and searching. Existing ClipboardDoubleClickTests guard against accidental auto-paste regression.

macOS Swift compilation and UI interactions must be validated on a macOS runner or directly on the Mac. Visual similarity is an implementation goal, not a certified pixel-perfect match; proprietary icons and cloud sharing are excluded.

Initial implementation is on feature/paste-style-clipboard-ui. Merge only after macOS CI succeeds; ad-hoc signed builds remain test-only until AOM Dev is a valid code-signing identity.
