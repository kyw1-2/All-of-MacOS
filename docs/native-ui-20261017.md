# Native UI refinement of the supplied 1.2.0 archive

Base: supplied source archive at commit 6b47683fc1db2274e5149d80efd30f359b5759f1. App version remains 1.2.0; build is 2026101706.

- Native NavigationSplitView and sidebar List, standard window toolbar and title bar.
- Native gesture List supports keyboard focus/selection; device filter uses a segmented Picker. Reconcile selection on scope/search/filter changes.
- Action commands consolidated into a menu; copy and nested branch insertion now have explicit callbacks in the workspace.
- Settings use a native category sidebar. System appearance is the new fallback, while explicit saved appearance preferences remain intact.
- Capture, clipboard and window tiling actions move into the window toolbar. Reduced decorative shadows, tinted cards and oversized capture buttons.
- All app ScrollView constructors hide indicators. AppKit Lists, Forms and text editors use a window-scoped policy with weak ownership and reentrancy guards. Wheel/trackpad scrolling remains native. Standard system file dialogs retain OS behavior. No system-wide preference changes.

Validation: final full run of 772 tests passed (including the opt-in native rendering test), including three new AppKit policy tests for legacy tracks, framework resets, preserved document scroll position and released nested editors. An opt-in native rendering test covers light/dark gesture surfaces, capture, tiling and settings. The live isolated preview verified adding a gesture, scrolling the trigger chooser, adding an action and opening its menu with AppleShowScrollBars=Always passed to the preview process only. Further live UI checks were interrupted by the computer-use tool's native pipe closing. Independent AGY review was attempted but interrupted without a verdict; it is not counted as a pass.

Known validation limits: preview was exercised on macOS 27.2/Xcode 27.1, not every deployment OS. Existing Swift concurrency warnings remain outside this UI change. No production settings/presets were used for UI testing; no installation or remote publication is performed by this change.

Build locally with ALLOFMACOS_SKIP_AUTO_RELEASE=1 bash build-and-sign.sh. Do not omit that variable for a local-only build: the inherited build script otherwise attempts a private release upload.
