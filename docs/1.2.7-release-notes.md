# All of MacOS 1.2.7 — Clipboard Responsiveness

Build `2026101902`.

## Highlights
- Improved destination-app focus handoff before direct clipboard insertion.
- Moved copy-payload snapshots, rich-text preparation, preview generation and long-text search to background workers.
- Added cancellation and change-generation checks to prevent stale clipboard work from replacing newer content.
- Versioned thumbnail and preview caches so edits invalidate old image previews.
- Improved selection recovery when items are removed while searching.

## Verification and limits
The full test suite reported **858 passing tests, zero failures and 10 conditional skips** (mostly display-dependent cases). A synthetic delayed clipboard-provider experiment measured a short UI-thread polling return but did **not** measure end-to-end insertion latency. Real destination-app and physical-device behavior were not exhaustively tested.
