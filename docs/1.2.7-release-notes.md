# AOM 1.2.7 — Clipboard responsiveness

2026-10-19 · build 2026101902 · based on 1.2.6 (`a44b54c`).

## Findings and fixes

| Observed source behavior | Change |
| --- | --- |
| Pasteboard payload reads ran on the UI thread; a source application can supply promised data slowly | Read bounded snapshots on a dedicated worker, separate from decoding/hashing. Validate change counts, privacy settings and capture generations before accepting results. Poll every 75 ms instead of 150 ms |
| A nonactivating shelf could retain keyboard focus while the destination was already frontmost | Hide the shelf and relinquish key focus before dispatching paste. The ready destination receives one send immediately; wait only for actual activation |
| Multi-item composition, including unnecessary attributed copies of plain text, ran synchronously | Prepare payloads asynchronously; skip rich-text construction for plain-only selections. Cancellation, a newer copy, deletion or content edits invalidate pending preparation |
| Each search scanned full text on the UI thread | Search snapshots on a cancellable worker; reject obsolete query results, disable pending-query paste fallback, restore the deletion neighbor after results arrive |
| Repeated preview rendering counted entire strings, parsed RTF and decoded full images | Prepare bounded cached previews off the UI thread. Preserve rich text, bound image previews to 1,200 pixels, and set native text storage once per content version |
| Edited images retained stale thumbnails because their entry ID stayed the same | Version thumbnail and preview cache keys by content revision; keep old archives compatible through an optional revision field |

The synchronous clipboard-write API remains available to existing callers. Shelf paste uses the asynchronous path. The app identifier and stable AOM Dev signing identity remain unchanged; no clipboard/history reset is required.

## Verification

- Full `swift test -j 2`: **858 tests, zero failures, 10 conditional skips** (nine require an active display; one requires opt-in native UI rendering). This includes 19 new clipboard tests.
- A separate process supplies promised pasteboard data after 350 ms. The AOM main-actor polling call returned in **0.78 ms** in the full-suite run (0.51 ms in the focused run), and a UI-actor task ran while the provider was still pending. This measures main-thread return, not total copy/paste latency.
- Large-history asynchronous search dispatch returned in **0.033 ms**; matching happens afterward on a worker. This is not total search latency.
- Deterministic checks cover focus release before a single send, changed-clipboard/cancellation protection, edits during preparation, obsolete searches, deletion selection, rich-text preservation, content-version invalidation and bounded image decoding.
- Focused clipboard suite: 89 tests passed before the final three regression tests were added; those three are included in the full suite above.
- `git diff --check`: passed. Signed-bundle diagnostics, DMG identity/digest and installation evidence are recorded in the GitHub release.

A slow source provider still determines when its data becomes available. Polling cannot capture every replacement occurring faster than its sampling interval. Native text storage installation occurs on the UI thread once prepared; this is not a complete shelf rewrite. Display-dependent and physical keyboard/receiving-app checks remain unverified while the Mac is locked/asleep.
